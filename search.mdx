---
title: "Search"
description: "Turn a company, drug, program, target or indication name into its id."
icon: "search"
---

`GET /v1/search` finds entities by name and returns the id to pass as a
filter everywhere else. Start here.

## Key fields

| Field | Description |
| --- | --- |
| `type` | `company`, `drug`, `program`, `target` or `indication`. |
| `id` | Pass as `company_id`, `drug_id`, `program_id`, `target` or `indication`. |
| `name` | Display name. |
| `detail` | Country, highest phase, or company and indication. |
| `program_count` | Programs linked to the match. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `q` | Name or text, 2+ characters | `tirzepatide` |
| `types` | `company`, `drug`, `program`, `target`, `indication`; default all | `drug,program` |
| `limit` | Matches per type, 1–20, default 5 | `2` |

Results are not paginated. See [Conventions](/conventions).

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/search \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=tirzepatide" \
  --data-urlencode "types=drug,program" \
  --data-urlencode "limit=2"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/search",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "tirzepatide", "types": "drug,program", "limit": 2},
)
resp.raise_for_status()
for hit in resp.json()["data"]:
    print(hit["type"], hit["id"], hit["name"])
```
