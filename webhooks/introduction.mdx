description: "Push delivery of change events. Planned, not yet available."

---

Webhooks are planned. They will send you a signed event when a program is
added, discontinued or changes phase.

Until then, poll [`GET /v1/programs`](/datasets/programs) sorted by
`last_updated`:

```bash
curl "https://api.pav.bio/v1/programs?sort=-last_updated&from=2026-09-01" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

This returns programs whose latest event, such as a phase change, readout,
filing or approval, is on or after `from`, newest first. Run it on a schedule
and move `from` forward each time. It shows which programs changed, but not
what the previous value was.
