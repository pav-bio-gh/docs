Each API key may make **300 requests per minute**. Every `/v1` request and
every MCP tool call counts. Need more? Contact Pav at [pav.bio](https://pav.bio).

## Errors

Every error returns `{ "error": { "code", "message", "request_id" } }`, and
every response carries the same id in `X-Request-ID`. Quote it to support.

| Status | `code` | When | Retry |
| --- | --- | --- | --- |
| `400` | `validation_error` | Invalid or unknown parameter. | No |
| `401` | `unauthorized` | Missing or invalid key. | No |
| `403` | `forbidden` | Key lacks `pav:pipeline:read`. | No |
| `404` | `not_found` | Unknown id or route. | No |
| `429` | `rate_limited` | Over 300 requests/minute. | After `Retry-After` |
| `503` | `unavailable` | Busy or query timed out (30 s). | After `Retry-After: 5` |
| `500` | `error` | Unexpected error. | With backoff |

`GET /healthz` needs no key and returns `200` while the API is up.

## Retry

<CodeGroup>

```bash cURL icon="braces"
# --retry retries 429 and 5xx responses and waits for Retry-After.
curl --retry 5 "https://api.pav.bio/v1/companies?ticker=PFE" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

# Retries 429 and 5xx responses, waiting for Retry-After (2 retries by default).
client = Pav(max_retries=5)
print(client.companies.list(ticker=["PFE"]).items[0].name)
```

```bash CLI icon="terminal"
# Retries 429 and 5xx responses, waiting for Retry-After.
pav companies list --ticker PFE --retries 5
```
