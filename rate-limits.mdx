## Rate limits

Each API key may make **300 requests per minute**, with bursts up to 300,
counted across the whole service. Every REST request to a `/v1` endpoint and
every MCP tool call counts as one request. Connecting an MCP client and
listing its tools do not count.

Over the limit, the API returns `429 Too Many Requests` with a `Retry-After`
header in seconds. The message repeats the wait, because MCP tool errors carry
only the body:

```json Example 429 response
{
  "error": {
    "code": "rate_limited",
    "message": "Rate limit exceeded for this API key; retry after 1 seconds",
    "request_id": "847f481e923e48db81bf16cfc8812074"
  }
}
```

Wait `Retry-After` seconds before the next request. Very high request volume
from a single IP address can also return `429`, without a JSON body.

<Note>
Need a higher limit? Contact Pav at [pav.bio](https://pav.bio).
</Note>

## Timeouts

A request that runs longer than 30 seconds is cut off. A query the service
cannot finish in time, or a moment when the service is busy, returns `503`
with code `unavailable` and `Retry-After: 5`. Retry after the wait; narrowing
the request (a smaller `limit`, more filters) also helps.

## Health check

`GET /healthz` and `HEAD /healthz` need no key and return `200` while the API
is up.

## Error envelope

Every error has the same shape, and every response carries an `X-Request-ID`
header with the same id. Quote the `request_id` when you contact Pav support.

```json Example 422 response
{
  "error": {
    "code": "validation_error",
    "message": "query.status.0: Input should be 'active', 'inactive' or 'discontinued'",
    "request_id": "0e813a21760241db8eb9dcf77fe3735a"
  }
}
```

| Status | `code` | When | Retry? |
| --- | --- | --- | --- |
| `401` | `unauthorized` | Missing, malformed, unknown, revoked or expired key. | No. Fix the key. |
| `403` | `forbidden` | The key declares scopes but not `pav:pipeline:read`. | No. |
| `404` | `not_found` | Unknown id or route. | No. |
| `410` | `error` | A retired parameter (`active_since` on companies). | No. Remove the parameter. |
| `422` | `validation_error` | Invalid parameter: unknown enum value, bad id format, out-of-range `limit`, or a parameter the endpoint does not support. | No. Fix the request. |
| `429` | `rate_limited` | Over the per-key rate limit. | Yes, after `Retry-After`. |
| `503` | `unavailable` | The service is busy, a query ran out of time, or key verification is briefly unavailable. | Yes, after `Retry-After` when present, else with backoff. |
| `500` | `error` | Unexpected server error. | Yes, with backoff. Report the `request_id` if it persists. |

## Retry pattern

Retry `429`, `500` and `503`. Do not retry `4xx` validation or auth errors.

<CodeGroup>

```python Python
import os
import time
import requests

API = "https://api.pav.bio"
HEADERS = {"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"}


def pav_get(path, params=None, attempts=5):
    for attempt in range(attempts):
        resp = requests.get(f"{API}{path}", headers=HEADERS, params=params, timeout=60)
        if resp.status_code in (429, 503):
            time.sleep(int(resp.headers.get("Retry-After", str(2**attempt))))
            continue
        if resp.status_code == 500:
            time.sleep(2**attempt)
            continue
        resp.raise_for_status()
        return resp.json()
    raise RuntimeError(f"gave up on {path} after {attempts} attempts")


print(pav_get("/v1/stats")["assets"])
```

```javascript JavaScript
const API = "https://api.pav.bio";
const headers = { Authorization: `Bearer ${process.env.PAV_API_KEY}` };

async function pavGet(path, params = {}, attempts = 5) {
  for (let attempt = 0; attempt < attempts; attempt++) {
    const resp = await fetch(`${API}${path}?${new URLSearchParams(params)}`, { headers });
    if (resp.status === 429 || resp.status === 503) {
      const wait = Number(resp.headers.get("Retry-After") ?? 2 ** attempt);
      await new Promise((r) => setTimeout(r, wait * 1000));
      continue;
    }
    if (resp.status === 500) {
      await new Promise((r) => setTimeout(r, 2 ** attempt * 1000));
      continue;
    }
    if (!resp.ok) throw new Error(`HTTP ${resp.status}: ${await resp.text()}`);
    return resp.json();
  }
  throw new Error(`gave up on ${path} after ${attempts} attempts`);
}

console.log((await pavGet("/v1/stats")).assets);
```
