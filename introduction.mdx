The Pav API serves drug programs and the evidence around them (trials, deals,
patents and FDA records) as JSON over a read-only REST API and an MCP server.
Both use one API key and one rate limit. Every resource is one list endpoint,
filtered by plain values you already know (a ticker, a phase, a modality),
and one get endpoint by id.
