The Pav API serves biopharma pipeline data. It covers drug programs, the drugs
and companies behind them, and the clinical trials, deals, patents and FDA
records around them.

You can call it as a read-only REST API, use the Python SDK or the CLI, or
connect an AI assistant to the MCP server. All of them use the same data and
the same rate limit.
