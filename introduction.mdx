Pav tracks drug development programs and the evidence around them: who is
developing what, for which indication, at which phase, in which trials, under
which deals, and protected by which patents. The Pav API serves that data as
JSON. The same data is available to AI agents through the Pav MCP server.

## Ways to integrate

Both use the same API key, return the same JSON, and share one rate limit.
