Every endpoint is a read-only `GET` under `https://api.pav.bio/v1`. These
pages are built from the [OpenAPI spec](/openapi-and-agents).

Send your API key in the `Authorization` header as `Bearer <api_key>`. See
[Authentication](/authentication).

Each resource has a list endpoint and a get endpoint. See
[Fetching data](/fetching-data) for filters, sorting and paging.
