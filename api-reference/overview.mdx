Every endpoint is a read-only `GET` under `https://api.pav.bio/v1`, generated
from the [OpenAPI spec](/openapi-and-agents). Send
`Authorization: Bearer <api_key>` ([Authentication](/authentication)). Each
resource has one list endpoint, filtered by plain values (a ticker, a phase,
a modality) or by an id from an earlier response, and one get endpoint.
Lists return `{ "data": [...], "next_cursor": "...", "total": N }`; pass
`next_cursor` back as `cursor` for the next page.
