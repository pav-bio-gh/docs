Every endpoint is a read-only `GET` under `https://api.pav.bio/v1`, generated
from the [OpenAPI spec](/openapi-and-agents). Send
`Authorization: Bearer <api_key>` ([Authentication](/authentication)). Ids,
filters, dates, sorting and paging follow [Conventions](/conventions).
