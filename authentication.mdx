---
title: "Authentication"
description: "Send a Pav API key as a bearer token on every request."
icon: "key-round"
---

Every `/v1` endpoint and the MCP server take a Pav API key:

```http
Authorization: Bearer <your_api_key>
```

Create a personal or organization key at [app.pav.bio](https://app.pav.bio)
under **Settings → Developer**. The secret is shown once. To rotate, create a
new key, move clients to it, then revoke the old one; revocation takes effect
within minutes. A key created with custom scopes needs `pav:pipeline:read`.
Keep keys out of source control and client-side code.

| Status | `code` | When |
| --- | --- | --- |
| `401` | `unauthorized` | Missing, unknown, revoked or expired key. |
| `403` | `forbidden` | The key's scopes lack `pav:pipeline:read`. |
| `503` | `unavailable` | Key verification briefly unavailable; retry. |

```json Example 401 response
{
  "error": {
    "code": "unauthorized",
    "message": "Missing or invalid API key",
    "request_id": "b734c48c19304a37b6d66e7f1a623264"
  }
}
```
