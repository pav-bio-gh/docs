## Connect

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http pav https://api.pav.bio/mcp --header "Authorization: Bearer <api_key>"
    ```
  </Tab>
  <Tab title="Cursor and others">
    For clients that take a URL and headers (Cursor: `~/.cursor/mcp.json`):

    ```json mcp.json
    {
      "mcpServers": {
        "pav": {
          "url": "https://api.pav.bio/mcp",
          "headers": { "Authorization": "Bearer <api_key>" }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import asyncio
    import os

    from fastmcp import Client
    from fastmcp.client.transports import StreamableHttpTransport

    transport = StreamableHttpTransport(
        "https://api.pav.bio/mcp",
        headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    )


    async def main():
        async with Client(transport) as client:
            programs = await client.call_tool(
                "list_programs",
                {"phase": ["preclinical"], "modality": ["adc"], "company_type": "private", "view": "slim", "limit": 3},
            )
            for p in programs.structured_content["data"]:
                print(p["company"], "|", p["indication"], "|", p["phase"])


    asyncio.run(main())
    ```

    ```text Example output
    Earendil Labs | Colorectal cancer | preclinical
    Earendil Labs | Colorectal cancer | preclinical
    Earendil Labs | Other solid tumors | preclinical
    ```
  </Tab>
</Tabs>

## Tools

Each tool takes the endpoint's parameters and returns its JSON. Filter by a
plain value you already have (a ticker, a phase, a modality) — `company_id`,
`drug_id` and `program_id` are also accepted for ids from a previous
response.

| Tool | Endpoint |
| --- | --- |
| `list_programs`, `get_program` | `/v1/programs`, `/{program_id}` |
| `list_drugs`, `get_drug` | `/v1/drugs`, `/{drug_id}` |
| `list_companies`, `get_company` | `/v1/companies`, `/{company_id}` |
| `list_trials`, `get_trial` | `/v1/trials`, `/{nct_id}` |
| `list_deals`, `get_deal` | `/v1/deals`, `/{deal_id}` |
| `list_patents`, `get_patent_family` | `/v1/patents`, `/{id}` |
| `list_orange_book_products`, `list_orange_book_patents`, `list_orange_book_exclusivities`, `list_purple_book_products`, `list_orphan_designations`, `list_warning_letters`, `list_recalls`, `list_drug_applications`, `list_complete_response_letters`, `list_accelerated_approvals`, `list_advisory_committee_meetings` | One list per [FDA record type](/datasets/fda): `/v1/recalls`, `/v1/orange-book-patents`, … |
| `get_orange_book_product`, `get_orange_book_patent`, `get_orange_book_exclusivity`, `get_purple_book_product`, `get_orphan_designation`, `get_warning_letter`, `get_recall`, `get_drug_application`, `get_complete_response_letter`, `get_accelerated_approval`, `get_advisory_committee_meeting` | `/v1/<resource>/{record_key}`; a drug application by `/v1/drug-applications/{application_key}` |
| `get_stats` | `/v1/stats` |

Each tool call counts toward the [rate limit](/rate-limits).
