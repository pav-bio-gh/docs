| Dataset | Source |
| --- | --- |
| Programs, drugs | Company pipelines, filings and announcements; ClinicalTrials.gov |
| Companies | Company pipelines, ClinicalTrials.gov sponsors, SEC, USPTO, FDA |
| Clinical trials | ClinicalTrials.gov |
| Deals | SEC filings and company press releases |
| Patents | USPTO |
| FDA records | Orange Book and Purple Book (current monthly editions), orphan designations, Drugs@FDA, letters, approvals, meetings, recalls |
| Ontology terms | MONDO, NCIT, HGNC |

Every record links to its source (`source_url`, `nct_url`, deal source
documents, patent and FDA numbers). A filter on a partly populated field
returns only rows where the field is set — `company_type` is maintained
directly and reliable, but only around a fifth of tracked companies with an
active program have a `country` on file, so a `country` filter under-counts.
Report a data issue with the record id and the response `request_id` at
[pav.bio](https://pav.bio).
