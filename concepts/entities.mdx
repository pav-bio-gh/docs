title: "Entities"

---

The API is organized around five entities — **programs**, **companies**,
**clinical trials**, **deals** and **patent families** — plus a **changes** feed
that tracks pipeline updates.

```
company ──< program ──< clinical_trial
   │             │
   │             └──< indication_term (ontology)
   ├──< deal            (as a party, with roles)
   └──< patent_family   (as an owner)
```

A company owns many programs; a program links to the clinical trials Pav has
matched to it and to the ontology terms resolved from its indication text.
Deals and patent families link to companies through `company_id`, so any
company id from `/v1/companies` filters `/v1/deals` and `/v1/patents`.

## Program

A program is a single drug/asset row from a company's pipeline, deduplicated on
`(company, drug, indication, territory)`. Phase is a versioned attribute of a
program, not part of its identity — a phase change updates the existing row
rather than creating a new one.

| Field | Notes |
| --- | --- |
| `id` | Durable Pav program identifier. Use it for get-by-id and `similar-programs`. |
| `company_id`, `short_name`, `company` | Owning company (id, internal slug, display name). |
| `drug` | Asset/drug name as published. |
| `indication` | Indication as published by the company. |
| `phase` / `phase_norm` | Raw label and the canonical normalized phase. |
| `modality` / `modality_norm` | Raw label and the canonical normalized modality. `modality_norm` may be null. |
| `target` | Molecular target. Partial coverage — null for many programs. |
| `mechanism_of_action` | Mechanism, when published. |
| `territory` | Region the program applies to, when disclosed. |
| `clinical_trials[]` | Trials linked to this program. |
| `indication_terms[]` | Resolved ontology terms (e.g. MONDO) for the indication. |
| `source_url`, `source_run_id`, `source_scraped_at` | Provenance of the snapshot. |

Endpoints: `GET /v1/programs`, `GET /v1/programs/{id}`,
`GET /v1/programs/{id}/similar-programs`, `GET /v1/programs/autocomplete`.

## Company

| Field | Notes |
| --- | --- |
| `company_id` | Durable Pav company identifier. |
| `short_name` | Internal slug, stable join key. |
| `name`, `status`, `country` | Display name, status (e.g. public/private), HQ country. |
| `asset_count` | Number of programs Pav tracks for the company. |
| `last_scraped_at` | Most recent pipeline scrape (UTC). |

Endpoints: `GET /v1/companies`, `GET /v1/companies/{id}`,
`GET /v1/companies/{id}/programs`, `GET /v1/companies/{id}/changes`.

## Clinical trial

A trial is a ClinicalTrials.gov record, keyed by its `nct_id`.

| Field | Notes |
| --- | --- |
| `nct_id`, `nct_url` | Registry id and canonical URL. |
| `title`, `phase`, `status`, `study_type` | As reported by ClinicalTrials.gov. |
| `sponsor`, `conditions[]`, `enrollment_count` | Trial metadata. |
| `program_count`, `company_short_names[]` | Pav programs/companies linked to the trial. |
| `start_date`, `last_update_post_date` | Registry dates. |

<Note>
Trial search and listing both use the product trial index, which Pav builds from
ClinicalTrials.gov data plus Pav's program/company mappings and serves from
TurboPuffer. See [Hybrid Search](/concepts/hybrid-search).
</Note>

Endpoints: `GET /v1/trials`, `GET /v1/trials/{nct_id}`.

## Deal

A deal is one transaction — acquisition, merger, asset purchase, licensing,
collaboration, option, joint venture or distribution — extracted from SEC
filings and press releases. It keeps a stable `deal_id` as new documents update
it.

| Field | Notes |
| --- | --- |
| `deal_id` | Stable Pav deal id (UUID). |
| `deal_name`, `summary` | Headline and one-paragraph summary. |
| `deal_type` | `acquisition`, `merger`, `asset_purchase`, `licensing`, `collaboration`, `option`, `joint_venture`, `distribution`, `other`. |
| `latest_event_type` | Current lifecycle state: `proposed`, `announced`, `completed`, `amended`, `terminated`, or `update` (a mention that changed no state). |
| `announced_at`, `completed_at`, `activity_date` | Lifecycle dates (UTC). `activity_date` is the default sort. |
| `companies[]` | Parties resolved to Pav companies, with their `roles`. |
| `total_value`, `upfront`, `*_milestones` | Stated economics: `raw_text`, `amount`, `currency`, `percentage`, `not_disclosed`, `evidence`. |

`GET /v1/deals/{deal_id}` adds `terms` (headline value, upfront, equity,
milestones, royalties, territories, rights), lifecycle `events[]` with the
`source_url` that reported each one, and `source_documents[]`.

`q` on deals is an exact-term full-text match (all terms must match) or a party
name substring. It does not expand synonyms, so search each phrasing you need.

Endpoints: `GET /v1/deals`, `GET /v1/deals/{deal_id}`.

## Patent family

A patent family is a US root application with its continuations, divisionals
and provisionals, from the current USPTO snapshot.

| Field | Notes |
| --- | --- |
| `family_id` | Pav family id (the root application number). |
| `representative_title` | Title of the representative member. |
| `member_count`, `granted_count`, `pending_count` | Family size and status mix. |
| `earliest_priority_date`, `latest_grant_date`, `latest_status_date` | Key dates. |
| `has_live_member` | True when any member is pending or in force. |
| `owner_names[]`, `companies[]` | Recorded owners of live members, and those resolved to Pav companies. |
| `members[]` | Member applications (with `include_members=true` on the list). |

`GET /v1/patents/{family_id}` adds member ownership, recorded conveyances
(`ownership[]`), prosecution and maintenance `events[]`, CPC codes, and the
statutory term (earliest nonprovisional filing + 20 years, no adjustments).

Endpoints: `GET /v1/patents`, `GET /v1/patents/{family_id}`.

## Changes

The changes feed records detected pipeline changes per company: `change_type`
(e.g. `phase_change`, `added`, `removed`), the before/after phase, fuzzy
match scores linking the program across snapshots, and `detected_at`. Retracted
changes carry `invalidated_at`/`invalidation_reason` and surface only with
`include_invalidated=true`.

Endpoints: `GET /v1/changes`, `GET /v1/companies/{id}/changes`.
