Every list endpoint takes an optional free-text `q` and a set of structured
filters. How `q` behaves depends on the dataset.

## How `q` works

| Dataset | `q` behavior | Ordering |
| --- | --- | --- |
| Programs, companies, clinical trials | **Relevance search.** Finds records by meaning as well as by exact words: `oral GLP-1 obesity` ranks an "oral small molecule selective glucagon-like peptide-1 receptor (GLP-1R) agonist" in "Metabolic (Obesity)" near the top. | Best match first. `pagination.total` is `null`. |
| Drugs | **Exact name.** A complete INN, research code or brand; case, spaces, hyphens and trademark signs are ignored. | Most advanced phase first. |
| Deals | **Exact terms.** Every term must appear (word forms such as plurals also match) in the deal name, event headline, summary or rights, or `q` is a substring of a party's name. | The chosen `sort` (latest activity by default). |
| Patents | **Number or substring.** A patent, publication or application number in any format finds its family; other text matches the title, an owner name, or the trade name or ingredient of an approved drug listing the family's patents. | The chosen `sort` (latest status date by default). |
| FDA records | **Substring**, case-insensitive. Matches the title, description, company name, FDA organization name or an FDA identifier. | The chosen `sort` (issue date by default). |

`%` and `_` in `q` are matched literally, not as wildcards. On programs,
companies and trials, a `q` with no letters or digits returns no rows.

Deal, patent and FDA search do not expand synonyms or aliases. Search each drug
name, code name, target alias or spelling you care about, for example
`tirzepatide` and `LY3298176`, or use the program, drug and deal filters,
which do match aliases.

Short queries carry less meaning. For relevance search, prefer a phrase such as
`KRAS G12C inhibitor` over `KRAS`, or use the `target=KRAS` filter.

### Program search in detail

- `q` reads the drug's type: `siRNA for hypercholesterolemia`,
  `oral small molecule GLP-1 receptor agonist obesity` and
  `BCMA CAR-T multiple myeloma` rank programs of the named type first.
- A disease in `q` also finds programs for its narrower diseases:
  `pancreatic cancer` finds pancreatic ductal adenocarcinoma programs.
- `sort`, `include_total=true`, or a page past 1,000 rows switch `q` to a
  listing of every program matching all of its words, with an exact total.
- Trial `q` treats a written phase ("phase 3") as `phase=` when no `phase` is
  passed.

## Filters combine with AND

- Different filters combine with **AND**.
- Repeating one filter matches **any** of its values:
  `phase=Phase 2&phase=Phase 3`.
- `q` and filters combine with **AND**: filters narrow the ranked results.

```bash
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=antibody-drug conjugate" \
  --data-urlencode "phase=Phase 2" \
  --data-urlencode "phase=Phase 3" \
  --data-urlencode "limit=5"
```

## Accepted filter values

| Filter | Accepts | Unknown value |
| --- | --- | --- |
| Program `phase` | Normalized labels: `Preclinical`, `Phase 1`, `Phase 1/2`, `Phase 2`, `Phase 2/3`, `Phase 3`, `Filed`, `Registration`, `Approved` | Empty result |
| Program, drug `status` | `active`, `inactive`, `discontinued` | `422` |
| Program and deal `modality` | Modality token or display label (`small_molecule`, `Small molecule`), a nucleic-acid subclass (`siRNA`, `mRNA`, `ASO`), or a format (`bispecific`, `antibody_drug_conjugate`) | `422`, listing the accepted forms |
| Program and deal `target` | The target as written, a term label or id (NCIT, HGNC), a gene symbol or a common alias: `TL1A` = `TNFSF15` = `NCIT:C18289` | Empty result |
| Program `indication` | The indication as written, a MONDO label, id or exact synonym; includes narrower diseases | Empty result |
| Program `drug` | Drug name; case, punctuation and trademark signs ignored; also matches inside combinations | Empty result |
| Program `company` | Company name, slug or another known name (`MSD`) | Empty result |
| Trial `condition` | Disease name or synonym, MeSH id or MONDO id; includes narrower conditions | Empty result |
| Trial `phase`, `status` | Any case and format: `Phase 3`, `PHASE3`, `Recruiting` | Empty result |
| Trial `sponsor` | Lead sponsor name as registered, any case | Empty result |
| Deal `therapeutic_area` | Area slugs listed on [Deals](/datasets/deals#filters) | `422` |
| Deal `deal_type`, `event_type`, patent `state`, sorts | Closed lists in the [API Reference](/api-reference/deals/list-and-search-deals) | `422` |

Program, drug, patent and FDA `company_id` filters include the companies a
company owns. On programs, drugs and patents, `include_subsidiaries=false`
limits them to the company itself. The `company_id` filters on
`/v1/trials`, deals and the change feeds match the company itself.
See [Companies](/datasets/companies#parents-and-subsidiaries).

List the modalities, and active program counts for each phase and modality,
with [`GET /v1/stats`](/api-reference/stats/dataset-summary-statistics):

```json Example response (trimmed): GET /v1/stats
{
  "assets": 14253,
  "companies": 3382,
  "distinct_phases": 9,
  "distinct_modalities": 19,
  "by_phase": { "Phase 1": 3725, "Phase 2": 2977, "Phase 3": 2283, "Preclinical": 1632, "Approved": 1445 },
  "by_modality": { "small_molecule": 4342, "antibody": 2269, "cell_therapy": 1059, "adc": 817, "biologic_other": 651 }
}
```

<Warning>
Filters on partially populated fields (`target`, `modality`) return only
programs where the field is set. A program with no published target never
matches `target=KRAS`, even if it is a KRAS program. When recall matters, run
`q` as well and merge. See [Coverage and sources](/concepts/coverage-and-sources).
</Warning>

## Group by ontology terms

Each program carries `indication_terms` (MONDO) and `target_terms` (NCIT or
HGNC, with `gene_symbol`) where mapped. Group by `term_id` or `gene_symbol` to
merge phrasings such as `Obesity` and `Metabolic (Obesity)`, or `GLP-1R` and
`GLP-1 receptor`.

## Typeahead

`GET /v1/programs/autocomplete?q=tirzep` returns up to 25 suggested programs
(company, drug, indication) for a search box. It accepts the `phase`,
`modality`, `company`, `drug`, `indication` and `target` filters.

```json Example response (trimmed)
[
  { "id": 1831, "company": "Eli Lilly", "company_id": 218, "drug": "Tirzepatide", "indication": "Cardiovascular Outcomes", "phase_norm": "Approved" },
  { "id": 1833, "company": "Eli Lilly", "company_id": 218, "drug": "Tirzepatide", "indication": "Metabolic Dysfunction-Associated Steatotic Liver Disease", "phase_norm": "Phase 3" }
]
```
