List the programs against a target, most advanced first, then count how many
sit in each phase.

## 1. List programs against the target

`target` matches the target under any of its names. Lists page with
`next_cursor`; the Python SDK and the CLI's `--page-all` follow it for you.

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d target=TL1A \
  -d sort=-phase \
  -d view=slim \
  -d limit=3
```

```python Python SDK
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

programs = client.programs.list(
    target=["TL1A"],
    sort="-phase",
    view="slim",
    limit=3,
)
for program in programs.items:
    print(program.phase, program.company, program.drug, program.indication)
```

```bash CLI
pav programs list \
  --target TL1A \
  --sort=-phase \
  --view slim \
  --limit 3
```

## 2. Count programs in a phase

Every list returns `total`, the number of matches across all pages. Add
`phase` and read it.

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d target=TL1A \
  -d phase=phase_3 \
  -d limit=1
```

```python Python SDK
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

programs = client.programs.list(target=["TL1A"], phase=["phase_3"], limit=1)
print(programs.response.total)
```

```bash CLI
pav programs list \
  --target TL1A \
  --phase phase_3 \
  --limit 1 \
  --query total
```

</CodeGroup>

```text Example output
9
```

For a company's own pipeline instead of a target, filter with
`company=<ticker or name>`; it rolls up subsidiaries. For an indication, use
`indication=<name>`.
