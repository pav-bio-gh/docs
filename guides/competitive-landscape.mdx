List every program against a target and count by phase. Requires
`PAV_API_KEY`; the cURL and CLI versions also use `jq`.

1. `GET /v1/programs?target=<name>` lists programs under any name for the
   target; follow `next_cursor` to the end.
2. Count by `phase` and print the most advanced.

<CodeGroup>

```bash cURL
target=TL1A
programs="" cursor=""
while :; do
  page=$(curl -sfG https://api.pav.bio/v1/programs -H "Authorization: Bearer $PAV_API_KEY" \
    --data-urlencode "target=$target" --data-urlencode "view=slim" \
    --data-urlencode "sort=-phase" --data-urlencode "limit=200" \
    ${cursor:+--data-urlencode "cursor=$cursor"})
  programs+=$(jq -c '.data[]' <<< "$page")$'\n'
  cursor=$(jq -r '.next_cursor // empty' <<< "$page")
  [ -z "$cursor" ] && break
done
programs=$(grep . <<< "$programs")
echo "$target: $(wc -l <<< "$programs" | tr -d ' ') programs"
jq -r '.phase' <<< "$programs" | sort | uniq -c | sort -rn
jq -r '"\(.phase) | \(.company) | \(.drug) | \(.indication)"' <<< "$programs" | head -4
```

```python Python SDK
import collections

from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY
target = "TL1A"
# Iterating a list follows next_cursor across every page.
programs = list(client.programs.list(target=[target], view="slim", sort="-phase", limit=200))

print(f"{target}: {len(programs)} programs")
for phase, n in collections.Counter(p.phase for p in programs).most_common():
    print(f"  {phase:<12} {n}")
for p in programs[:4]:
    print(f"{p.phase:<10} | {p.company} | {p.drug} | {p.indication}")
```

```bash CLI
target=TL1A
programs=$(pav programs list --target "$target" --view slim --sort=-phase --limit 200 \
  --page-all --page-limit 100 --format jsonl | jq -c '.data[]? // .')
echo "$target: $(wc -l <<< "$programs" | tr -d ' ') programs"
jq -r '.phase' <<< "$programs" | sort | uniq -c | sort -rn
jq -r '"\(.phase) | \(.company) | \(.drug) | \(.indication)"' <<< "$programs" | head -4
```

`indication=<name>`.
