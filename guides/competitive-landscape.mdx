List every program against a target and count by phase. Requires
`PAV_API_KEY` and `pip install requests`.

1. `GET /v1/programs?target=<name>` lists programs under any name for the
   target; follow `next_cursor` to the end.
2. Count by `phase` and print the most advanced.

```python landscape.py
import collections
import os

import requests

API = "https://api.pav.bio/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"}


def get(path, **params):
    resp = requests.get(f"{API}{path}", headers=HEADERS, params=params, timeout=60)
    resp.raise_for_status()
    return resp.json()


target = "TL1A"
programs, params = [], {"target": target, "view": "slim", "sort": "-phase", "limit": 200}
while True:
    page = get("/programs", **params)
    programs += page["data"]
    if "next_cursor" not in page:
        break
    params["cursor"] = page["next_cursor"]

print(f"{target}: {len(programs)} programs")
for phase, n in collections.Counter(p["phase"] for p in programs).most_common():
    print(f"  {phase:<12} {n}")
for p in programs[:4]:
    print(f"{p['phase']:<10} | {p['company']} | {p['drug']} | {p['indication']}")
```

For a company's own pipeline instead of a target, filter with
`company=<ticker or name>`; it rolls up subsidiaries. For an indication, use
`indication=<name>`.
