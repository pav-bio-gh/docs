Find the target's id, list every program against it, and count by phase.
Requires `PAV_API_KEY` and `pip install requests`.

1. `GET /v1/search?types=target` returns the target's ontology id.
2. `GET /v1/programs?target=<id>` lists programs under any name for the
   target; follow `next_cursor` to the end.
3. Count by `phase_norm` and print the most advanced.

```python landscape.py
import collections
import os

import requests

API = "https://api.pav.bio/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"}


def get(path, **params):
    resp = requests.get(f"{API}{path}", headers=HEADERS, params=params, timeout=60)
    resp.raise_for_status()
    return resp.json()


target = get("/search", q="TL1A", types="target", limit=1)["data"][0]
programs, params = [], {"target": target["id"], "view": "slim", "sort": "-phase", "limit": 200}
while True:
    page = get("/programs", **params)
    programs += page["data"]
    if "next_cursor" not in page:
        break
    params["cursor"] = page["next_cursor"]

print(f"{target['name']} ({target['id']}): {len(programs)} programs")
for phase, n in collections.Counter(p["phase_norm"] for p in programs).most_common():
    print(f"  {phase:<12} {n}")
for p in programs[:4]:
    print(f"{p['phase_norm']:<8} | {p['company']} | {p['drug']} | {p['indication']}")
```

For one asset's nearest competitors, call
`GET /v1/programs/{program_id}/similar-programs`. For an indication, search
`types=indication` and filter with `indication=<id>`.
