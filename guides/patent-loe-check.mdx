List a drug's Orange Book patent and exclusivity expiries and its live US
patent families. Requires `PAV_API_KEY` and `pip install requests`.

1. `GET /v1/search?types=drug` confirms the drug and its id.
2. `GET /v1/fda/orange-book-patents` and `/orange-book-exclusivities` with
   `q=<ingredient>` list listings; follow `next_cursor` and keep one row per
   patent.
3. `GET /v1/patents?q=<name>&status=live` lists live families.

```python loe_check.py
import os

import requests

API = "https://api.pav.bio/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"}


def get(path, **params):
    resp = requests.get(f"{API}{path}", headers=HEADERS, params=params, timeout=60)
    resp.raise_for_status()
    return resp.json()


def every(path, **params):
    params["limit"] = 200
    while True:
        page = get(path, **params)
        yield from page["data"]
        if "next_cursor" not in page:
            return
        params["cursor"] = page["next_cursor"]


drug = get("/search", q="tirzepatide", types="drug", limit=1)["data"][0]
name = drug["name"]
expiry = {}
for r in every("/fda/orange-book-patents", q=name, sort="event_date"):
    expiry[r["patent_number"]] = r["event_date"]
print(f"{name} (drug_id {drug['id']}): {len(expiry)} Orange Book patents, last expires {max(expiry.values())}")
for r in every("/fda/orange-book-exclusivities", q=name, sort="-event_date"):
    print(f"  exclusivity {r['status']} until {r['event_date']}")
    break
families = get("/patents", q=name, status="live", view="slim", limit=3)
print(f"{families['total']} live US patent families, e.g.:")
for f in families["data"]:
    print(f"  {f['family_id']} | priority {f['earliest_priority_date']} | {f['representative_title']}")
```

```text Example output
Tirzepatide (drug_id 4781): 10 Orange Book patents, last expires 2041-12-30
  exclusivity NPP until 2028-12-19
11 live US patent families, e.g.:
  63477734 | priority 2022-12-29 | PROCESSES AND INTERMEDIATES FOR PREPARING TIRZEPATIDE
  19062335 | priority 2025-02-25 | MULTI-DOSE PEN OF TIRZEPATIDE
  63150187 | priority 2021-02-17 | TIRZEPATIDE THERAPEUTIC METHODS
```

`statutory_term_end` on `GET /v1/patents/{family_id}` is the earliest
nonprovisional filing plus 20 years, without extensions.
