See when a drug's Orange Book patents and exclusivities run out, using its FDA
product key (Mounjaro 2.5 mg, `N:215866:001`). Find product keys with
`GET /v1/orange-book-products?company=<ticker or name>`.

## 1. Patents, latest expiry first

<CodeGroup>

```bash cURL icon="braces"
curl -G https://api.pav.bio/v1/orange-book-patents \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d product_key=N:215866:001 \
  -d sort=-event_date \
  -d limit=3
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

patents = client.orange_book_patents.list(
    product_key="N:215866:001",
    sort="-event_date",
    limit=3,
)
for patent in patents.items:
    print(patent.patent_number, patent.event_date)
```

```bash CLI icon="terminal"
pav orange-book-patents list \
  --product-key N:215866:001 \
  --sort=-event_date \
  --limit 3
```

## 2. Exclusivities

<CodeGroup>

```bash cURL icon="braces"
curl -G https://api.pav.bio/v1/orange-book-exclusivities \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d product_key=N:215866:001 \
  -d sort=-event_date
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

exclusivities = client.orange_book_exclusivities.list(
    product_key="N:215866:001",
    sort="-event_date",
)
for exclusivity in exclusivities.items:
    print(exclusivity.status, exclusivity.event_date)
```

```bash CLI icon="terminal"
pav orange-book-exclusivities list \
  --product-key N:215866:001 \
  --sort=-event_date
```

</CodeGroup>

```json Example response (trimmed)
{
  "data": [
    {
      "status": "NPP",
      "event_date": "2028-12-19"
    },
    {
      "status": "NCE",
      "event_date": "2027-05-13"
    }
  ],
  "total": 2
}
```

`status` is the exclusivity code (`NCE`, new chemical entity; `NPP`, new patient
population). For the company's US patent families, list `GET /v1/patents` with
`company=<ticker or name>&status=live`; `statutory_term_end` on
`GET /v1/patents/{family_id}` is the earliest nonprovisional filing plus 20
years, without extensions.
