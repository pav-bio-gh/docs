List a company's Orange Book patent and exclusivity expiries and its live US
patent families, then narrow to one product. Requires `PAV_API_KEY`; the cURL
and CLI versions also use `jq`.

1. `GET /v1/orange-book-patents` and `/v1/orange-book-exclusivities` with
   `company=<ticker or name>` list every listing for the company; follow
   `next_cursor` and keep the rows for the product you want.
2. `GET /v1/patents?company=<ticker or name>&status=live` lists its live
   families.

<CodeGroup>

```bash cURL
company=lilly product=tirzepatide
every() {  # every row of a list endpoint, one JSON object per line
  local path=$1 cursor=""; shift
  while :; do
    page=$(curl -sfG "https://api.pav.bio/v1$path" -H "Authorization: Bearer $PAV_API_KEY" --data-urlencode "limit=200" \
      "$@" ${cursor:+--data-urlencode "cursor=$cursor"})
    jq -c '.data[]' <<< "$page"
    cursor=$(jq -r '.next_cursor // empty' <<< "$page")
    [ -z "$cursor" ] && return
  done
}
patents=$(every /orange-book-patents --data-urlencode "company=$company" --data-urlencode "sort=event_date" \
  | jq -c --arg p "$product" 'select((.description // "") | ascii_downcase | contains($p))')
echo "$product: $(jq -r '.patent_number' <<< "$patents" | sort -u | wc -l | tr -d ' ') Orange Book patents, last expires $(jq -r '.event_date' <<< "$patents" | sort | tail -1)"
every /orange-book-exclusivities --data-urlencode "company=$company" --data-urlencode "sort=-event_date" \
  | jq -r --arg p "$product" 'select((.description // "") | ascii_downcase | contains($p)) | "  exclusivity \(.status) until \(.event_date)"' | head -1
families=$(curl -sfG https://api.pav.bio/v1/patents -H "Authorization: Bearer $PAV_API_KEY" --data-urlencode "company=$company" \
  --data-urlencode "status=live" --data-urlencode "view=slim" --data-urlencode "limit=200")
jq -r --arg p "$product" '[.data[] | select((.representative_title // "") | ascii_downcase | contains($p))] as $m
  | "\($m | length) of \(.total) live US patent families mention \($p), e.g.:",
    ($m[:3][] | "  \(.family_id) | priority \(.earliest_priority_date) | \(.representative_title)")' <<< "$families"
```

```python Python SDK
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY
company, product = "lilly", "tirzepatide"

# Iterating a list follows next_cursor across every page.
expiry = {
    r.patent_number: r.event_date
    for r in client.orange_book_patents.list(company=[company], sort="event_date", limit=200)
    if product in (r.description or "").lower()
}
print(f"{product}: {len(expiry)} Orange Book patents, last expires {max(expiry.values())}")
for r in client.orange_book_exclusivities.list(company=[company], sort="-event_date", limit=200):
    if product in (r.description or "").lower():
        print(f"  exclusivity {r.status} until {r.event_date}")
        break
families = client.patents.list(company=[company], status=["live"], view="slim", limit=200)
matches = [f for f in families.items if product in (f.representative_title or "").lower()]
print(f"{len(matches)} of {families.response.total} live US patent families mention {product}, e.g.:")
for f in matches[:3]:
    print(f"  {f.family_id} | priority {f.earliest_priority_date} | {f.representative_title}")
```

```bash CLI
company=lilly product=tirzepatide
patents=$(pav orange-book-patents list --company "$company" --sort=event_date --limit 200 \
    --page-all --page-limit 100 --format jsonl | jq -c '.data[]? // .' \
  | jq -c --arg p "$product" 'select((.description // "") | ascii_downcase | contains($p))')
echo "$product: $(jq -r '.patent_number' <<< "$patents" | sort -u | wc -l | tr -d ' ') Orange Book patents, last expires $(jq -r '.event_date' <<< "$patents" | sort | tail -1)"
pav orange-book-exclusivities list --company "$company" --sort=-event_date --limit 200 \
    --page-all --page-limit 100 --format jsonl | jq -c '.data[]? // .' \
  | jq -r --arg p "$product" 'select((.description // "") | ascii_downcase | contains($p)) | "  exclusivity \(.status) until \(.event_date)"' | head -1
pav patents list --company "$company" --status live --view slim --limit 200 --format json \
  | jq -r --arg p "$product" '[.data[] | select((.representative_title // "") | ascii_downcase | contains($p))] as $m
    | "\($m | length) of \(.total) live US patent families mention \($p), e.g.:",
      ($m[:3][] | "  \(.family_id) | priority \(.earliest_priority_date) | \(.representative_title)")'
```

`statutory_term_end` on `GET /v1/patents/{family_id}` is the earliest
nonprovisional filing plus 20 years, without extensions. Look up one patent
directly with `GET /v1/patents/{patent_number}`.
