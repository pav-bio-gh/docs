List deals against a target by potential value, and open the top deal.
Requires `PAV_API_KEY`; the cURL and CLI versions also use `jq`.

1. `GET /v1/deals?target=<name>&sort=-total_potential_value` lists deals
   covering drugs against it; follow `next_cursor` for more.
2. `GET /v1/deals/{deal_id}` returns full terms, events and sources.

<CodeGroup>

```bash cURL
page=$(curl -sfG https://api.pav.bio/v1/deals -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "target=GLP-1R" --data-urlencode "deal_type=licensing,collaboration" \
  --data-urlencode "sort=-total_potential_value" --data-urlencode "limit=3")
jq -r '"GLP-1R: \(.total) licensing and collaboration deals"' <<< "$page"
jq -r '.data[] | "\(.announced_at[:10]) | $\((.total_potential_value.amount // 0) / 1e7 | round / 100)B | \(.deal_name)"' <<< "$page"
top=$(jq -r '.data[0].deal_id' <<< "$page")
curl -sf "https://api.pav.bio/v1/deals/$top" -H "Authorization: Bearer $PAV_API_KEY" | jq -r '"Upfront: \(.upfront.raw_text)"'
```

```python Python SDK
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY
target = "GLP-1R"
page = client.deals.list(target=[target], deal_type=["licensing", "collaboration"],
                         sort="-total_potential_value", limit=3)
print(f"{target}: {page.response.total} licensing and collaboration deals")
for d in page.items:
    value = d.total_potential_value.amount if d.total_potential_value else None
    print(f"{d.announced_at.date()} | ${value / 1e9:.2f}B | {d.deal_name}" if value else d.deal_name)

top = client.deals.get(page.items[0].deal_id)
print("Upfront:", top.upfront.raw_text if top.upfront else None)
```

```bash CLI
page=$(pav deals list --target GLP-1R --deal-type licensing,collaboration \
  --sort=-total_potential_value --limit 3 --format json)
jq -r '"GLP-1R: \(.total) licensing and collaboration deals"' <<< "$page"
jq -r '.data[] | "\(.announced_at[:10]) | $\((.total_potential_value.amount // 0) / 1e7 | round / 100)B | \(.deal_name)"' <<< "$page"
pav deals get --deal-id "$(jq -r '.data[0].deal_id' <<< "$page")" --format json --query upfront.raw_text
```

Read `raw_text` and `evidence` for qualifiers such as "up to". `min_value_usd`
and value sorts consider only deals with a stated value. Filter by company
instead with `company=<ticker or name>`.
