Find the biggest licensing and collaboration deals against a target, then open
the top one for its terms.

## 1. List deals against the target

Largest stated value first.

<CodeGroup>

```bash cURL icon="braces"
curl -G https://api.pav.bio/v1/deals \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d target=GLP-1R \
  -d deal_type=licensing,collaboration \
  -d sort=-total_potential_value \
  -d limit=3
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

deals = client.deals.list(
    target=["GLP-1R"],
    deal_type=["licensing", "collaboration"],
    sort="-total_potential_value",
    limit=3,
)
for deal in deals.items:
    print(deal.deal_id, deal.deal_name)
```

```bash CLI icon="terminal"
pav deals list \
  --target GLP-1R \
  --deal-type licensing,collaboration \
  --sort=-total_potential_value \
  --limit 3
```

## 2. Open the top deal

<CodeGroup>

```bash cURL icon="braces"
curl https://api.pav.bio/v1/deals/c7870330-f6b0-43cb-842c-b215c4e522dc \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

deal = client.deals.get("c7870330-f6b0-43cb-842c-b215c4e522dc")
print(deal.upfront.raw_text)
print(deal.total_potential_value.raw_text)
```

```bash CLI icon="terminal"
pav deals get --deal-id c7870330-f6b0-43cb-842c-b215c4e522dc
```

</CodeGroup>

```json Example response (trimmed)
{
  "deal_name": "Exclusive global license agreement for SYH2086",
  "upfront": {
    "raw_text": "an upfront payment of $120 million"
  },
  "total_potential_value": {
    "raw_text": "an upfront payment of $120 million + up to $2 billion in milestone payments"
  }
}
```

Read `raw_text` and `evidence` for qualifiers such as "up to". `min_value_usd`
and value sorts consider only deals with a stated value. Filter by company
instead with `company=<ticker or name>`.
