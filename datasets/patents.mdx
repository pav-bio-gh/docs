## Overview

A patent family is a US root application together with its continuations,
divisionals and provisionals. Each family carries its members and their
status, recorded owners (and the Pav companies they are linked to), recorded
assignments, prosecution and maintenance events, CPC classes, the
FDA-approved drugs whose Orange Book listing names one of its patents, and a
statutory term end date.

Questions this dataset answers:

- Which live, granted US patent families does a company own?
- Which families cover a drug, and who owns them?
- Which family does patent `US 9,474,780 B2` belong to, and which products list it?
- When does a family's statutory term end?

## Coverage

| Families | Live families | Source | Linked to a Pav company |
| --- | --- | --- | --- |
| 123,000+ (September 2026) | 109,000+ | USPTO applications, grants and assignment records | About a third of live families |

<Warning>
No rows for a company does not mean the company holds no patents. An owner
that is not a Pav company (a university or an untracked company) is still
listed in `owner_names`; search it with `q`.
</Warning>

## Key fields

| Field | Description |
| --- | --- |
| `family_id` | Pav family id. |
| `representative_title` | Title of the representative member. |
| `member_count`, `granted_count`, `pending_count` | Family size and status mix. |
| `earliest_priority_date`, `earliest_filing_date`, `latest_grant_date`, `latest_status_date` | Key dates. |
| `has_live_member` | `true` when any member is pending or in force. |
| `owner_names[]` | Recorded owners of live members, as recorded. |
| `companies[]` | Owners linked to Pav companies. |
| `drugs[]` | FDA-approved products whose Orange Book listing names one of the family's patents: `trade_name`, `ingredient`, `application_key`, `patent_numbers`, `latest_patent_expiry` (including pediatric exclusivity). Biologics are not covered, because the Purple Book lists no patents. |
| `members[]` | Member applications (list endpoint: with `include_members=true`, up to 30 per family). |

`GET /v1/patents/{family_id}` adds `statutory_term_start` and
`statutory_term_end`, family `cpc_codes`, per-member owners, recorded
conveyances in `ownership[]`, and prosecution and maintenance `events[]`.

<Note>
`statutory_term_end` is the earliest nonprovisional filing date plus 20 years.
It does not include patent term adjustments or extensions. Treat it as a
baseline for loss-of-exclusivity work, not a final expiry date.
</Note>

## Endpoints

| Endpoint | Use |
| --- | --- |
| `GET /v1/patents` | Search and filter families. |
| `GET /v1/patents/{family_id}` | One family with members, ownership, events, drugs and term. |

## Filters

All filters are optional and combine with AND.

| Parameter | Matches | Example |
| --- | --- | --- |
| `q` | A patent, publication or application number in any common format finds its family. Any other text matches a substring of the title or an owner name, or the trade name or ingredient of an FDA-approved drug listing one of the family's patents. No synonym expansion. | `tirzepatide`, `US 9,474,780 B2`, `2021/0363216`, `14/987,791` |
| `company_id` | Families whose live members a Pav company owns, including the companies it owns unless `include_subsidiaries=false`. Repeatable. | `218` |
| `cpc` | CPC class prefix on any member. Spacing is ignored. | `C07K`, `A61K38/26` |
| `state` | `live` (a member pending or in force) or `lapsed` (none). | `live` |
| `granted` | `true`: at least one grant; `false`: none. | `true` |
| `priority_from`, `priority_to` | Earliest priority date range, inclusive. | `2020-01-01` |
| `include_members` | Include member applications. | `true` |
| `sort` | `latest_status_date` (default), `earliest_priority_date`, `member_count`; newest or largest first. | `earliest_priority_date` |
| `include_total` | Exact match count. | `true` |
| `limit`, `offset` | Page size (1–100, default 25) and offset (up to 10,000). | `limit=50` |

A lapsed family has no live owners, so `company_id` with `state=lapsed`
returns nothing.

## A company's live granted families

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/patents \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "company_id=218" \
  --data-urlencode "state=live" \
  --data-urlencode "granted=true" \
  --data-urlencode "include_total=true" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/patents",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"company_id": 218, "state": "live", "granted": "true", "include_total": "true", "limit": 3},
)
resp.raise_for_status()
body = resp.json()
print("total:", body["pagination"]["total"])
for f in body["data"]:
    print(f["family_id"], "|", f["representative_title"], "|", f.get("earliest_priority_date"))
```

```javascript JavaScript
const params = new URLSearchParams({
  company_id: "218",
  state: "live",
  granted: "true",
  include_total: "true",
  limit: "3",
});
const resp = await fetch(`https://api.pav.bio/v1/patents?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const body = await resp.json();
console.log("total:", body.pagination.total);
for (const f of body.data) console.log(f.family_id, "|", f.representative_title, "|", f.earliest_priority_date);
```

## Families that mention a drug

`q` matches titles, owner names and the drugs listing a family's patents, so it
finds families from every owner, including owners that are not Pav companies.

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/patents \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=tirzepatide" \
  --data-urlencode "include_total=true" \
  --data-urlencode "limit=5"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/patents",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "tirzepatide", "include_total": "true", "limit": 5},
)
resp.raise_for_status()
for f in resp.json()["data"]:
    print(f["family_id"], "|", f["representative_title"], "|", ", ".join(f.get("owner_names", [])))
```

```javascript JavaScript
const params = new URLSearchParams({ q: "tirzepatide", include_total: "true", limit: "5" });
const resp = await fetch(`https://api.pav.bio/v1/patents?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const { data } = await resp.json();
for (const f of data) console.log(f.family_id, "|", f.representative_title, "|", (f.owner_names ?? []).join(", "));
```

## Look up a patent number

Any common format of a patent, publication or application number finds its
family. `drugs[]` shows the approved products whose Orange Book listing names
the patent.

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/patents \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=US 9,474,780 B2"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/patents",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "US 9,474,780 B2"},
)
resp.raise_for_status()
for f in resp.json()["data"]:
    print(f["family_id"], "|", f["representative_title"])
    for d in f["drugs"]:
        print("  ", d["trade_name"], "|", d["application_key"], "|", d["latest_patent_expiry"])
```

```javascript JavaScript
const params = new URLSearchParams({ q: "US 9,474,780 B2" });
const resp = await fetch(`https://api.pav.bio/v1/patents?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const { data } = await resp.json();
for (const f of data) {
  console.log(f.family_id, "|", f.representative_title);
  for (const d of f.drugs) console.log("  ", d.trade_name, "|", d.application_key, "|", d.latest_patent_expiry);
}
```
