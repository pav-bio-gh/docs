A patent family groups the US applications and patents that share a priority
claim. It carries the owners and the FDA-approved drugs that list its patents.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/patents` | Families that match your filters. |
| `GET /v1/patents/{id}` | One family, by Pav `family_id` or by a member's patent, publication or application number. |

## Fields

The main fields on a patent family. The [API reference](/api-reference/patents/list-patent-families)
lists every field.

<ResponseField name="family_id" type="string">
  Pav patent family id.
</ResponseField>

<ResponseField name="representative_title" type="string | null">
  Family title.
</ResponseField>

<ResponseField name="member_count" type="integer">
  Applications in the family.
</ResponseField>

<ResponseField name="granted_count" type="integer">
  Granted members.
</ResponseField>

<ResponseField name="pending_count" type="integer">
  Pending members.
</ResponseField>

<ResponseField name="has_live_member" type="boolean">
  `true` when a member is pending or in force.
</ResponseField>

<ResponseField name="earliest_priority_date" type="string | null">
  Earliest priority date.
</ResponseField>

<ResponseField name="latest_grant_date" type="string | null">
  Most recent grant.
</ResponseField>

<ResponseField name="owner_names" type="string[]">
  Owners as recorded.
</ResponseField>

<ResponseField name="companies" type="object[]">
  Owners linked to Pav companies.
</ResponseField>

<ResponseField name="drugs" type="object[]">
  FDA-approved drugs whose Orange Book listing names one of the family's
  patents.
</ResponseField>

<ResponseField name="members" type="object[]">
  Up to 30 members with their numbers and status. Left out with `view=slim`.
</ResponseField>

<ResponseField name="statutory_term_end" type="string | null">
  Earliest nonprovisional filing plus 20 years, without term adjustments or
  extensions. On the get endpoint only.
</ResponseField>

## Filters

See [Fetching data](/fetching-data) for how filters, dates, sorting and paging
work.

<ParamField query="company" type="string">
  Ticker, company slug or exact company name. Matches owners of a live member.
  Example: `lilly`.
</ParamField>

<ParamField query="patent_number" type="string">
  A member's patent, publication or application number. Example: `12295987`.
</ParamField>

<ParamField query="cpc" type="string">
  CPC code prefix on any member. Example: `A61K38/26`.
</ParamField>

<ParamField query="status" type="string">
  `live` (a member is pending or in force) or `lapsed`.
</ParamField>

<ParamField query="granted" type="boolean">
  `true` for families with at least one granted member.
</ParamField>

<ParamField query="company_id" type="string">
  One or more Pav company ids.
</ParamField>

<ParamField query="from" type="date">
  Families with `earliest_priority_date` on or after this date.
</ParamField>

<ParamField query="to" type="date">
  Families with `earliest_priority_date` on or before this date.
</ParamField>

<ParamField query="sort" type="string" default="-latest_status_date">
  `latest_status_date`, `earliest_priority_date` or `member_count`. Prefix
  `-` for descending.
</ParamField>

<ParamField query="view" type="string" default="full">
  `full` or `slim`.
</ParamField>

## Example

<CodeGroup>

```bash cURL icon="braces"
curl -G https://api.pav.bio/v1/patents \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d company=lilly \
  -d status=live \
  -d view=slim \
  -d limit=2
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

families = client.patents.list(
    company=["lilly"],
    status=["live"],
    view="slim",
    limit=2,
)
for family in families.items:
    print(family.family_id, family.representative_title)
```

```bash CLI icon="terminal"
pav patents list \
  --company lilly \
  --status live \
  --view slim \
  --limit 2
```
