A patent family groups US applications and patents that share a priority
claim, with their owners and the FDA-approved drugs that list them.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/patents` | Families, filtered. |
| `GET /v1/patents/{id}` | One family, by Pav `family_id` or by a member's patent, publication or application number. |

## Key fields

| Field | Description |
| --- | --- |
| `family_id`, `representative_title` | Pav family id and title. |
| `member_count`, `granted_count`, `pending_count` | Members by status. |
| `has_live_member` | A member is pending or in force. |
| `earliest_priority_date`, `latest_grant_date` | Key dates. |
| `owner_names[]`, `companies[]` | Owners as recorded, and linked Pav companies. |
| `drugs[]` | Orange Book products that list a member. |
| `members[]` | Up to 30 members with numbers and status (`view=full`). |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `company` | Ticker, company slug or exact name; owner of a live member | `lilly` |
| `patent_number` | A member's patent, publication or application number | `12295987` |
| `cpc` | CPC prefix on any member | `A61K38/26` |
| `status` | `live`, `lapsed` | `live` |
| `granted` | `true`, `false` | `true` |
| `company_id` | Ids, for values from an earlier response | `218` |
| `from`, `to` | `earliest_priority_date` range | `2020-01-01` |
| `sort` | `latest_status_date` (default descending), `earliest_priority_date`, `member_count` | `-member_count` |
| `view` | `full`, `slim` | `slim` |

## Example

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/patents \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "company=lilly" \
  --data-urlencode "status=live" \
  --data-urlencode "view=slim" \
  --data-urlencode "limit=2"
```

```python Python SDK
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY
page = client.patents.list(company=["lilly"], status=["live"], view="slim", limit=2)
for f in page.items:
    print(f.family_id, f.latest_status_date, f.representative_title)
print("total:", page.response.total)
```

```bash CLI
pav patents list --company lilly --status live --view slim --limit 2
```
