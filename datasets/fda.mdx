## Overview

FDA records are regulatory records published by the US Food and Drug
Administration, with the applicant, sponsor or recipient linked to a Pav
company where possible. `GET /v1/fda` covers eleven record types, each with
the FDA identifiers you need to join it to other sources: application numbers,
product numbers, patent numbers and orphan designation ids.

Drug applications, complete response letters, accelerated approvals and
advisory committee meetings also have their own endpoints and an application
dossier. See [FDA applications and reviews](/datasets/fda-applications).

Questions this dataset answers:

- Which Orange Book patents and exclusivities protect a drug, and when do they expire?
- Which biosimilars of a reference biologic are licensed, and are they interchangeable?
- Which orphan designations does a company hold?
- Which listed patents expire in the next quarter?
- Which warning letters and recalls name a company?

<Warning>
Records that are not linked to a Pav company, most often warning letters and
recalls, never match `company_id`. Many of those recipients are pharmacies,
outsourcing facilities, distributors and consumer-product sellers that Pav
does not track. To cover a company fully, also search its FDA name with `q`,
for example `q=Pfizer`.
</Warning>

## Record keys

Every record has a durable `record_key` for `GET /v1/fda/{record_key}`, built
from FDA's own identifiers. It stays the same across FDA editions and stops
working only when FDA drops the record itself (a delisted product or an expired
listing).

| Record | Key format | Example |
| --- | --- | --- |
| Orange Book product | `orange_book_product:<application>:<product>` | `orange_book_product:N:215866:019` |
| Orange Book patent | `orange_book_patent:<application>:<product>:<patent>[:<use code>]` | `orange_book_patent:N:215866:018:9474780:U-4374` |
| Orange Book exclusivity | `orange_book_exclusivity:<application>:<product>:<code>:<expiry>` | `orange_book_exclusivity:N:215866:001:NCE:2027-05-13` |
| Purple Book product | `purple_book_product:<BLA>:<product>` | `purple_book_product:761059:006` |
| Orphan designation | `orphan_designation:<designation id>` | `orphan_designation:1141926` |
| Drug application | `drug_application:<application>` | `drug_application:N:215866` |

Filter by FDA identifier as well: `application_key`, `product_key`,
`patent_number` and `designation_id`.

## Key fields

| Field | Description |
| --- | --- |
| `record_key` | Durable key for `GET /v1/fda/{record_key}`. |
| `record_type` | One of the eleven types in the coverage table. |
| `source`, `source_version` | FDA publication, and its edition (`YYYY-MM` for Orange and Purple Book; the load date for orphan designations; `null` for continuously published sources). |
| `fda_organization_name` | Applicant, sponsor or recipient as FDA spells it. |
| `company` | The linked Pav company (`company_id`, `short_name`, `name`), when linked. |
| `application_key`, `product_key`, `patent_number`, `designation_id` | FDA identifiers, by record type. Application keys are `N:` (NDA), `A:` (ANDA) or `BLA:` plus the number. |
| `title` | Trade name; patent or exclusivity label; application product names; letter subject; recalled product; the product with an accelerated approval; or the meeting title. |
| `description` | Ingredient or proper name for products, patents and exclusivities; the designated indication; the letter subject or type; the recall reason; the approved indication; or the convening center. |
| `document_date` | The date FDA issued the record: approval, patent submission, designation, letter, recall, first approval of an application, accelerated approval or meeting day. Not set for exclusivities. |
| `event_date`, `event_date_type` | A dated event: `approval`, `patent_expiry`, `exclusivity_expiry`, `orphan_exclusivity_expiry`, `issued`, `posted`, `recall`, `latest_action`, `letter`, `meeting` or `projected_completion`. |
| `status` | Marketing status for products (`RX`, `OTC`, `DISCN`), `listed` for patents, the exclusivity code, designation status, letter or recall status, application or review status. |
| `source_url` | The official FDA page for the record. Orange Book patents and exclusivities link to their product's patent and exclusivity page. |
| `details` | Type-specific fields: strength, dosage form and route, TE code, RLD flag, `approval_date_raw`; patent use code, substance and product claim flags, pediatric extension; biosimilar pathway and licensure; orphan `approvals` and exclusivity dates; recall `brand`, reason and product types; letter issuing office. |

## Endpoints

| Endpoint | Use |
| --- | --- |
| `GET /v1/fda` | Search and filter FDA records of every type. |
| `GET /v1/fda/{record_key}` | One record by `record_key`. URL-encode the key: it can contain `/`, `:` and spaces. |
| `GET /v1/fda/applications`, `/complete-response-letters`, `/accelerated-approvals`, `/advisory-committee-meetings` | One record type each. See [FDA applications and reviews](/datasets/fda-applications). |
| `GET /v1/fda/applications/{application_key}` | An application with every FDA record on it and its submissions. |

## Filters

All filters are optional and combine with AND.

| Parameter | Matches | Example |
| --- | --- | --- |
| `q` | Case-insensitive substring of the title, description, company name, FDA organization name or an FDA identifier. No synonym expansion. `%` and `_` are matched literally. | `tirzepatide` |
| `company_id` | Records linked to these Pav companies or the companies they own. Repeatable. | `218` |
| `record_type` | Record types. Repeatable. | `orange_book_patent` |
| `application_key` | Exact FDA application. | `N:215866` |
| `product_key` | Exact application and product number. | `N:215866:019` |
| `patent_number` | Exact Orange Book patent number. | `9474780` |
| `designation_id` | Exact orphan designation id. | `1141926` |
| `date_field` | Which date `date_from`/`date_to` apply to: `document_date` (default, issue date) or `event_date` (for example a patent or exclusivity expiry). | `event_date` |
| `date_from`, `date_to` | Date range, inclusive. | `2027-01-01` |
| `sort`, `direction` | `document_date` (default) or `event_date`; `desc` (default) or `asc`. Missing dates sort last. | `sort=event_date&direction=asc` |
| `include_total` | Exact match count. | `true` |
| `limit`, `offset` | Page size (1–100, default 25) and offset. | `limit=100` |

## Orange Book patents and exclusivities for a drug

List an application's patents and exclusivities by expiry. A patent is listed
once per product and use code, so the same patent number repeats across rows.

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/fda \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "application_key=N:215866" \
  --data-urlencode "record_type=orange_book_patent" \
  --data-urlencode "record_type=orange_book_exclusivity" \
  --data-urlencode "sort=event_date" \
  --data-urlencode "direction=asc" \
  --data-urlencode "include_total=true" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/fda",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={
        "application_key": "N:215866",
        "record_type": ["orange_book_patent", "orange_book_exclusivity"],
        "sort": "event_date",
        "direction": "asc",
        "include_total": "true",
        "limit": 3,
    },
)
resp.raise_for_status()
body = resp.json()
print("total:", body["pagination"]["total"])
for r in body["data"]:
    print(r["event_date"], "|", r["record_type"], "|", r["title"], "|", r["status"])
```

```javascript JavaScript
const params = new URLSearchParams([
  ["application_key", "N:215866"],
  ["record_type", "orange_book_patent"],
  ["record_type", "orange_book_exclusivity"],
  ["sort", "event_date"],
  ["direction", "asc"],
  ["include_total", "true"],
  ["limit", "3"],
]);
const resp = await fetch(`https://api.pav.bio/v1/fda?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const body = await resp.json();
console.log("total:", body.pagination.total);
for (const r of body.data) console.log(r.event_date, "|", r.record_type, "|", r.title, "|", r.status);
```

## Biosimilars of a reference biologic

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/fda \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=adalimumab" \
  --data-urlencode "record_type=purple_book_product" \
  --data-urlencode "include_total=true" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/fda",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "adalimumab", "record_type": "purple_book_product", "include_total": "true", "limit": 3},
)
resp.raise_for_status()
for r in resp.json()["data"]:
    d = r.get("details", {})
    print(r["title"], "|", r["description"], "|", r["fda_organization_name"], "|", d.get("license_type"))
```

```javascript JavaScript
const params = new URLSearchParams({ q: "adalimumab", record_type: "purple_book_product", include_total: "true", limit: "3" });
const resp = await fetch(`https://api.pav.bio/v1/fda?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const { data } = await resp.json();
for (const r of data) console.log(r.title, "|", r.description, "|", r.fda_organization_name, "|", r.details?.license_type);
```

## Get one record

URL-encode the `record_key`.

<CodeGroup>

```bash cURL
curl https://api.pav.bio/v1/fda/orange_book_product%3AN%3A215866%3A019 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python
import os
from urllib.parse import quote

import requests

key = "orange_book_product:N:215866:019"
resp = requests.get(
    f"https://api.pav.bio/v1/fda/{quote(key, safe='')}",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
)
resp.raise_for_status()
record = resp.json()
print(record["title"], "|", record["details"]["strength"], "|", record["status"])
```

```javascript JavaScript
const key = "orange_book_product:N:215866:019";
const resp = await fetch(`https://api.pav.bio/v1/fda/${encodeURIComponent(key)}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
const record = await resp.json();
console.log(record.title, "|", record.details.strength, "|", record.status);
```
