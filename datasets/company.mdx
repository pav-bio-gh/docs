## Overview

One company, by the `company_id` from a list, with its tickers, website and owner
(when known). An unknown id returns a `404`.

<RequestExample>

```bash cURL icon="braces"
curl https://api.pav.bio/v1/companies/313 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

company = client.companies.get(313)
print(company.name, company.website)
```

```bash CLI icon="terminal"
pav companies get --company-id 313
```

</RequestExample>
