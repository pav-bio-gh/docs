title: "Program"

description: "A program by id, with its trials and ontology terms."
---

## Overview

Returns the program for a `program_id` from a list. It also carries the linked
clinical trials and the ontology terms for its indication and target. An
unknown id returns a `404`.

<RequestExample>

```bash cURL icon="braces"
curl https://api.pav.bio/v1/programs/3498 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

program = client.programs.get(3498)
print(program.drug, program.indication, program.phase)
```

```bash CLI icon="terminal"
pav programs get --program-id 3498
```

</RequestExample>
