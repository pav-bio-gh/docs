A program is one drug in one indication at one company, with its phase,
modality, target, status and linked trials.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/programs` | Programs, filtered. |
| `GET /v1/programs/{program_id}` | One program with trials and ontology terms. |

## Key fields

| Field | Description |
| --- | --- |
| `program_id` | Pav program id. |
| `status` | `active`, `inactive` (known only from trials, all closed) or `discontinued`. |
| `company_id`, `company` | Developing company. |
| `drug`, `drug_id` | Drug as published, and the Pav drug shared across companies. |
| `indication`, `indication_terms[]` | Indication as published, and its MONDO terms. |
| `phase` | Normalized: `preclinical`, `phase_1`, `phase_1_2`, `phase_2`, `phase_2_3`, `phase_3`, `filed`, `registration`, `approved`. |
| `modality`, `target`, `target_terms[]` | Normalized modality, target as published, and its NCIT or HGNC terms. |
| `clinical_trials[]`, `source_url`, `last_updated` | Linked trials, source page, last change. |

`view=slim` returns light rows with `trial_count` instead of nested trials
and terms.

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `company` | Ticker, company slug or exact name; rolls up subsidiaries | `PFE` |
| `company_type` | `public`, `private` | `private` |
| `country` | Company headquarters, exact name | `United States` |
| `drug` | Exact drug name, code or brand | `sotorasib` |
| `phase` | See key fields above (also takes `1`, `2`, `3`) | `preclinical,phase_1` |
| `indication` | Name, synonym or MONDO id; includes narrower diseases | `NSCLC` |
| `target` | Name, gene symbol or term id | `TL1A` |
| `modality` | Modality, subclass or format | `adc`, `bispecific` |
| `status` | `active` (default), `inactive`, `discontinued` | `discontinued` |
| `company_id`, `drug_id`, `program_id` | Ids, for values from an earlier response | `412` |
| `from`, `to` | `last_updated` range | `2026-09-01` |
| `sort` | `company`, `drug`, `indication`, `target`, `modality`, `phase`, `last_updated` | `-phase` |
| `view` | `full`, `slim` | `slim` |

`company_type` and `country` are company attributes: `company_type` is
maintained directly and reliable; only around a fifth of tracked companies
with an active program have a `country` on file, so a `country` filter
under-counts.

## Example

Phase 2 and 3 programs against TL1A, latest phase first:

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "target=TL1A" \
  --data-urlencode "phase=phase_2,phase_3" \
  --data-urlencode "sort=-phase" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/programs",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"target": "TL1A", "phase": "phase_2,phase_3", "sort": "-phase", "limit": 3},
)
resp.raise_for_status()
for p in resp.json()["data"]:
    print(p["program_id"], p["company"], "|", p["drug"], "|", p["indication"], "|", p["phase"])
```
