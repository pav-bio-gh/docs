## Overview

A program is a company's drug in an indication. It carries the phase,
modality, target, status and linked clinical trials. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

The example lists Phase 2 and 3 programs against TL1A, latest phase first.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/programs?target=TL1A&phase=phase_2,phase_3&sort=-phase&limit=3" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

programs = client.programs.list(
    target=["TL1A"],
    phase=["phase_2", "phase_3"],
    sort="-phase",
    limit=3,
)
for program in programs.items:
    print(program.company, program.drug, program.indication, program.phase)
```

```bash CLI icon="terminal"
pav programs list \
  --target TL1A \
  --phase phase_2,phase_3 \
  --sort=-phase \
  --limit 3
```

</RequestExample>
