## Overview

Records are keyed by FDA identifiers and linked to a Pav company where
possible. `from` and `to` filter on the patent expiry date. `status` is `listed`. A patent appears once per use code it is listed
with.

To get one record, call `GET /v1/orange-book-patents/{record_key}` with a `record_key`
from this list. URL-encode the key. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/orange-book-patents?company=lilly&sort=-event_date&limit=2" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

patents = client.orange_book_patents.list(
    company=["lilly"],
    sort="-event_date",
    limit=2,
)
for patent in patents.items:
    print(patent.patent_number, patent.event_date, patent.title)
```

```bash CLI icon="terminal"
pav orange-book-patents list \
  --company lilly \
  --sort=-event_date \
  --limit 2
```

</RequestExample>
