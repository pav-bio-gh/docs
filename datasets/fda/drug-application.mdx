---

## Overview

One NDA, ANDA or BLA, by its `application_key` (such as `N:209637`), with
every FDA record on it and its submissions. URL-encode the key.

<RequestExample>

```bash cURL icon="braces"
curl https://api.pav.bio/v1/drug-applications/N:209637 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

dossier = client.drug_applications.get("N:209637")
print(dossier.application.title, dossier.records_total)
```

```bash CLI icon="terminal"
pav drug-applications get --application-key N:209637
```

</RequestExample>
