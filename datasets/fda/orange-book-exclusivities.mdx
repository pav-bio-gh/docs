## Overview

Records are keyed by FDA identifiers and linked to a Pav company where
possible. `from` and `to` filter on the exclusivity expiry date. `status` is the exclusivity code, such as `NCE` (new chemical
entity) or `NPP` (new patient population).

To get one record, call `GET /v1/orange-book-exclusivities/{record_key}` with a `record_key`
from this list. URL-encode the key. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/orange-book-exclusivities?product_key=N:215866:001&sort=-event_date" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

exclusivities = client.orange_book_exclusivities.list(
    product_key="N:215866:001",
    sort="-event_date",
)
for exclusivity in exclusivities.items:
    print(exclusivity.status, exclusivity.event_date)
```

```bash CLI icon="terminal"
pav orange-book-exclusivities list \
  --product-key N:215866:001 \
  --sort=-event_date
```
