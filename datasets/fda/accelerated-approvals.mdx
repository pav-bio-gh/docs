## Overview

Records are keyed by FDA identifiers and linked to a Pav company where
possible. `from` and `to` filter on the approval date. `status` is `ongoing`, `verified` or `withdrawn`.

To get one record, call `GET /v1/accelerated-approvals/{record_key}` with a `record_key`
from this list. URL-encode the key. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/accelerated-approvals?limit=2" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

page = client.accelerated_approvals.list(limit=2)
for record in page.items:
    print(record.record_key, record.event_date, record.title)
```

```bash CLI icon="terminal"
pav accelerated-approvals list --limit 2
```

</RequestExample>
