## Overview

Records are keyed by FDA identifiers and linked to a Pav company where
possible. `from` and `to` filter on the first approval date. `status` takes values such as `approved`.

To get one record, call `GET /v1/drug-applications/{record_key}` with a `record_key`
from this list. URL-encode the key. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

To get one application with every FDA record on it and its submissions, use
[Drug Application](/datasets/fda/drug-application).

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/drug-applications?limit=2" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

page = client.drug_applications.list(limit=2)
for record in page.items:
    print(record.record_key, record.event_date, record.title)
```

```bash CLI icon="terminal"
pav drug-applications list --limit 2
```

</RequestExample>
