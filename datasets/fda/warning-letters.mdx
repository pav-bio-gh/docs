## Overview

Records are keyed by FDA identifiers and linked to a Pav company where
possible. `from` and `to` filter on the letter date. `status` takes values such as `issued`.

To get one record, call `GET /v1/warning-letters/{record_key}` with a `record_key`
from this list. URL-encode the key. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

Many warning letter recipients are not linked to a Pav company, so a
`company` filter misses some letters.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/warning-letters?limit=2" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

page = client.warning_letters.list(limit=2)
for record in page.items:
    print(record.record_key, record.event_date, record.title)
```

```bash CLI icon="terminal"
pav warning-letters list --limit 2
```

</RequestExample>
