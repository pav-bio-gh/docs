A company is one biopharma organization. Filtering any other dataset by a
company also includes the companies it owns.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/companies` | Companies that match your filters. |
| `GET /v1/companies/{company_id}` | One company with its tickers, owner and website. |

## Fields

The main fields on a company. The [API reference](/api-reference/companies/list-companies)
lists every field.

<ResponseField name="company_id" type="integer">
  Pav company id.
</ResponseField>

<ResponseField name="name" type="string">
  Company name.
</ResponseField>

<ResponseField name="company_type" type="string">
  `public` or `private`.
</ResponseField>

<ResponseField name="parent_company_id" type="integer | null">
  Pav id of the company that owns this one.
</ResponseField>

<ResponseField name="country" type="string | null">
  Headquarters country.
</ResponseField>

<ResponseField name="website" type="string | null">
  Company website.
</ResponseField>

<ResponseField name="tickers" type="object[]">
  Current stock tickers. Empty for a private company.
</ResponseField>

<ResponseField name="cik" type="string | null">
  SEC Central Index Key, for companies that file with the SEC.
</ResponseField>

<ResponseField name="asset_count" type="integer">
  Number of programs Pav tracks for the company.
</ResponseField>

<ResponseField name="last_checked_at" type="string | null">
  When Pav last read the company's pipeline.
</ResponseField>

## Filters

See [Fetching data](/fetching-data) for how filters, sorting and paging work.

<ParamField query="company" type="string">
  Company slug or exact registered name or synonym. A value that matches more
  than one company returns a `400` that lists the candidates. Example: `MSD`.
</ParamField>

<ParamField query="ticker" type="string">
  Current stock ticker. Example: `PFE`.
</ParamField>

<ParamField query="company_type" type="string">
  `public` or `private`.
</ParamField>

<ParamField query="country" type="string">
  Headquarters country, exact name. Example: `United States`.
</ParamField>

<ParamField query="has_pipeline" type="boolean">
  `true` for companies with a tracked pipeline, `false` for those without.
</ParamField>

<ParamField query="company_id" type="string">
  One or more Pav company ids.
</ParamField>

<ParamField query="sort" type="string" default="-asset_count">
  `asset_count` or `name`. Prefix `-` for descending.
</ParamField>

## Example

<CodeGroup>

```bash cURL icon="braces"
curl -G https://api.pav.bio/v1/companies \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d company=MSD
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

companies = client.companies.list(company=["MSD"])
for company in companies.items:
    print(company.company_id, company.name, company.asset_count)
```

```bash CLI icon="terminal"
pav companies list --company MSD
```
