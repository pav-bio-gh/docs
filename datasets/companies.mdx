## Overview

Companies are the biopharma organizations Pav tracks. Filtering any other dataset by a
company also includes the companies it owns. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

The example finds a company by a name it is known by.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/companies?company=MSD" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

companies = client.companies.list(company=["MSD"])
for company in companies.items:
    print(company.company_id, company.name, company.asset_count)
```

```bash CLI icon="terminal"
pav companies list --company MSD
```

</RequestExample>
