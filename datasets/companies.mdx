A company is one biopharma organization. Its `company_id` filters every
other dataset and includes the companies it owns.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/companies` | Companies by name, ticker or filter. |
| `GET /v1/companies/{company_id}` | One company with tickers, owner and website. |

## Key fields

| Field | Description |
| --- | --- |
| `company_id`, `name` | Pav company id and name. |
| `company_type` | `public` or `private`, maintained directly. |
| `parent_company_id` | Owning company, when owned. |
| `country`, `website` | Headquarters country and website. |
| `tickers[]`, `cik` | Stock tickers and SEC CIK. |
| `asset_count` | Programs tracked. |
| `last_checked_at` | When the company's pipeline was last read. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `company` | Slug or exact registered name/synonym | `MSD` |
| `ticker` | Current stock ticker | `PFE` |
| `company_type` | `public`, `private` | `public` |
| `country` | Headquarters, exact name | `United States` |
| `company_id` | Ids, for values from an earlier response | `313` |
| `has_pipeline` | `true` or `false` | `true` |
| `sort` | `asset_count` (default descending), `name` | `name` |

`company` and `ticker` are exact, not full-text: a value that matches more
than one tracked company is a `400` naming the candidates.

## Example

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/companies \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d company=MSD
```

```python Python SDK
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

companies = client.companies.list(company=["MSD"])
for company in companies.items:
    print(company.company_id, company.name, company.asset_count)
```

```bash CLI
pav companies list --company MSD
```
