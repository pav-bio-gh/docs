A company is one biopharma organization. Its `company_id` filters every
other dataset and includes the companies it owns.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/companies` | Companies by name or filter. |
| `GET /v1/companies/{company_id}` | One company with tickers, owner and website. |
| `GET /v1/companies/{company_id}/trials` | Trials linked to the company or a company it owns. |

## Key fields

| Field | Description |
| --- | --- |
| `company_id`, `name` | Pav company id and name. |
| `parent_company_id` | Owning company, when owned. |
| `country`, `website` | Headquarters country and website. |
| `tickers[]`, `cik` | Stock tickers and SEC CIK. |
| `asset_count` | Programs tracked. |
| `last_checked_at` | When the company's pipeline was last read. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `q` | Name or known alias, ranked | `MSD` |
| `company_id` | Ids | `313` |
| `has_pipeline` | `true` or `false` | `true` |
| `sort` | `asset_count` (default descending), `name` | `name` |

`/companies/{company_id}/trials` takes `via` (`program`, `sponsor`, `any`),
`phase`, `status`, `from`/`to` on `start_date`, and `sort`, as on
[Clinical trials](/datasets/clinical-trials). Shared rules:
[Conventions](/conventions).

## Example

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/companies \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=MSD" \
  --data-urlencode "limit=2"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/companies",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "MSD", "limit": 2},
)
resp.raise_for_status()
for c in resp.json()["data"]:
    print(c["company_id"], c["name"], c["asset_count"])
```
