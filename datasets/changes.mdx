---
title: "Changes"
description: "Programs added, dropped or changing phase; trials changing status, dates or results."
icon: "history"
---

`GET /v1/changes` lists detected changes, newest first. Poll it with `since`
to follow movement.

| `entity` | Covers |
| --- | --- |
| `program` (default) | Programs added (`insert`), changed (`update`) or dropped (`delete`). |
| `trial` | ClinicalTrials.gov changes by `kind`, from 2026-06-15. |

## Key fields

| Field | Description |
| --- | --- |
| `id` | Change id. |
| `program_id` or `nct_id` | What changed. |
| `company_id`, `company`, `drug`, `indication` | Program context. |
| `change_type` | `insert`, `update` or `delete`. |
| `prev_phase`, `new_phase` | Phase before and after (programs). |
| `kind`, `old_value`, `new_value` | What changed and its values (trials). |
| `detected_at` | When Pav detected the change. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `entity` | `program`, `trial` | `trial` |
| `company_id`, `program_id` | Ids | `218` |
| `nct_id` | NCT ids (`entity=trial`) | `NCT06771115` |
| `change_type` | `insert`, `update`, `delete` | `update` |
| `kind` | `trial`, `status`, `phase`, `start_date`, `primary_completion_date`, `completion_date`, `results_posted`, `enrollment`, `why_stopped` | `results_posted` |
| `since` | ISO 8601 timestamp on `detected_at` | `2026-09-01T00:00:00Z` |
| `include_invalidated` | `true`: include retracted program changes | `true` |

Shared rules: [Conventions](/conventions).

## Example

Eli Lilly's program changes:

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/changes \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "company_id=218" \
  --data-urlencode "limit=2"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/changes",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"company_id": 218, "limit": 2},
)
resp.raise_for_status()
for c in resp.json()["data"]:
    print(c["detected_at"][:10], c["change_type"], c["drug"], "|", c["indication"], "|", c.get("new_phase"))
```
