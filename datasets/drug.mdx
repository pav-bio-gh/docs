## Overview

Returns the drug for a `drug_id` from a list, with every company and program that
develops it. An unknown id returns a `404`.

<RequestExample>

```bash cURL icon="braces"
curl https://api.pav.bio/v1/drugs/869 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

drug = client.drugs.get(869)
print(drug.name, drug.highest_phase)
```

```bash CLI icon="terminal"
pav drugs get --drug-id 869
```

</RequestExample>
