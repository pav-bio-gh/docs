A drug groups every company's programs of one product under its INN,
research codes and brands.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/drugs` | Drugs by exact name or filter. |
| `GET /v1/drugs/{drug_id}` | One drug with its holders and programs. |

## Key fields

| Field | Description |
| --- | --- |
| `drug_id`, `name`, `inn` | Pav drug id, display name, INN. |
| `aliases[]` | Other names, each with `kind`: `inn`, `code` or `brand`. |
| `modality`, `modality_subclass` | Modality, and nucleic-acid class (`sirna`, `mrna`, …). |
| `highest_phase` | Most advanced phase across all holders. |
| `companies[]` | Each holder with `company_id`, `program_count`, `highest_phase`. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `q` | Exact name, code or brand; case and punctuation ignored | `Leqvio` |
| `drug_id`, `company_id` | Ids | `869` |
| `multi_company` | `true`: held by more than one company | `true` |
| `status` | Which programs count: `active` (default), `inactive`, `discontinued` | `active` |
| `sort` | `highest_phase` (default descending), `name`, `program_count` | `-program_count` |

Shared rules: [Conventions](/conventions).

## Example

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/drugs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=Leqvio"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/drugs",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "Leqvio"},
)
resp.raise_for_status()
for d in resp.json()["data"]:
    print(d["drug_id"], d["name"], [c["name"] for c in d["companies"]])
```
