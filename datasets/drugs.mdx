A drug groups every company's programs of one product. It holds the product's
INN, research codes and brand names.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/drugs` | Drugs that match your filters. |
| `GET /v1/drugs/{drug_id}` | One drug with its companies and programs. |

## Fields

The main fields on a drug. The [API reference](/api-reference/drugs/list-drugs)
lists every field.

<ResponseField name="drug_id" type="integer">
  Pav drug id.
</ResponseField>

<ResponseField name="name" type="string">
  Display name. The INN when there is one.
</ResponseField>

<ResponseField name="inn" type="string | null">
  International nonproprietary name.
</ResponseField>

<ResponseField name="aliases" type="object[]">
  Other names. Each has a `kind`: `inn`, `code` or `brand`.
</ResponseField>

<ResponseField name="modality" type="string | null">
  Normalized modality.
</ResponseField>

<ResponseField name="modality_subclass" type="string | null">
  Nucleic-acid class, such as `sirna` or `mrna`.
</ResponseField>

<ResponseField name="highest_phase" type="string | null">
  Most advanced phase across all companies, normalized.
</ResponseField>

<ResponseField name="program_count" type="integer">
  Programs of this drug across companies.
</ResponseField>

<ResponseField name="companies" type="object[]">
  Each company with programs of this drug, with its `company_id`,
  `program_count` and `highest_phase`.
</ResponseField>

## Filters

See [Fetching data](/fetching-data) for how filters, sorting and paging work.

<ParamField query="drug" type="string">
  Exact name, code or brand. Case and punctuation are ignored. Example:
  `Leqvio`.
</ParamField>

<ParamField query="company" type="string">
  Ticker, company slug or exact company name. Includes the companies it owns.
  Example: `sanofi`.
</ParamField>

<ParamField query="multi_company" type="boolean">
  `true` returns only drugs held by more than one company.
</ParamField>

<ParamField query="status" type="string" default="active">
  Which programs count toward the drug: `active`, `inactive` or
  `discontinued`.
</ParamField>

<ParamField query="drug_id" type="string">
  One or more Pav drug ids.
</ParamField>

<ParamField query="company_id" type="string">
  One or more Pav company ids.
</ParamField>

<ParamField query="sort" type="string" default="-highest_phase">
  `highest_phase`, `name` or `program_count`. Prefix `-` for descending.
</ParamField>

## Example

<CodeGroup>

```bash cURL icon="braces"
curl -G https://api.pav.bio/v1/drugs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d drug=Leqvio
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

drugs = client.drugs.list(drug=["Leqvio"])
for drug in drugs.items:
    print(drug.drug_id, drug.name, [company.name for company in drug.companies])
```

```bash CLI icon="terminal"
pav drugs list --drug Leqvio
```
