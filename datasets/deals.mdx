## Overview

A deal is one transaction between companies. It carries the stated terms, the
drugs covered, lifecycle events and source documents. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

## Deal Values

- `upfront` is the cash paid at signing or closing, plus any equity investment at its
  purchase price (for example $875M cash and a $650M stock purchase is a $1.525B upfront).
  An acquisition's announced price is never used as its upfront; the upfront is shown
  only when the source states the cash paid at closing.
- `total_potential_value` adds the upfront, fixed later payments, option fees and every
  milestone, CVR or earn-out at its stated maximum (an acquisition counts the largest of
  these once). Royalties, profit shares and cost sharing are not included.
- When a part has no stated amount, or is in another currency, it is not added and its
  name is listed in `terms.total_excludes`. If the announcement states a total, that
  stated total is shown instead of the partial sum.
- A larger stated total also wins over a complete sum, unless it is an enterprise value.
- `total_value` is the total exactly as the announcement states it.

The example lists oncology licensing deals announced in 2025 over $100M.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/deals?deal_type=licensing&therapeutic_area=oncology&from=2025-01-01&to=2025-12-31&min_value_usd=100000000&sort=-total_potential_value&limit=2" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
import datetime as dt

from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

deals = client.deals.list(
    deal_type=["licensing"],
    therapeutic_area=["oncology"],
    from_=dt.date(2025, 1, 1),
    to=dt.date(2025, 12, 31),
    min_value_usd=100_000_000,
    sort="-total_potential_value",
    limit=2,
)
for deal in deals.items:
    print(deal.announced_at.date(), deal.deal_name)
```

```bash CLI icon="terminal"
pav deals list \
  --deal-type licensing \
  --therapeutic-area oncology \
  --from 2025-01-01 \
  --to 2025-12-31 \
  --min-value-usd 100000000 \
  --sort=-total_potential_value \
  --limit 2
```
