A deal is one transaction between companies, with its stated terms, lifecycle
events, drugs covered and source documents.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/deals` | Deals, filtered. |
| `GET /v1/deals/{deal_id}` | One deal with full terms, events and sources. |

## Key fields

| Field | Description |
| --- | --- |
| `deal_id`, `deal_name`, `summary` | Pav deal id, name and summary. |
| `deal_type` | `acquisition`, `licensing`, `collaboration`, `option`, … |
| `latest_event_type` | Lifecycle state, filtered by `status`. |
| `announced_at`, `completed_at`, `activity_date` | Key dates. |
| `companies[]` | Parties with `company_id` and `roles` (`licensor`, `acquirer`, …). |
| `total_value`, `total_potential_value`, `upfront` | Each with `amount`, `currency`, `raw_text` and the `evidence` sentence. |
| `assets[]`, `targets[]`, `therapeutic_areas[]` | Drugs covered and their tags. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `company` | Ticker, company slug or exact name; any party | `abbvie` |
| `deal_type` | See key fields | `licensing` |
| `status` | `proposed`, `announced`, `completed`, `amended`, `terminated`, `update` | `completed` |
| `target`, `modality`, `therapeutic_area` | As on [Programs](/datasets/programs); areas such as `oncology` | `oncology` |
| `min_value_usd` | Minimum `total_potential_value` | `100000000` |
| `company_id`, `drug_id` | Ids, for values from an earlier response | `203` |
| `from`, `to` | `announced_at` range | `2025-01-01` |
| `sort` | `activity_date` (default descending), `announced_at`, `completed_at`, `total_value`, `total_potential_value` | `-total_potential_value` |

## Example

Oncology licensing deals announced in 2025 over $100M:

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/deals \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "deal_type=licensing" \
  --data-urlencode "therapeutic_area=oncology" \
  --data-urlencode "from=2025-01-01" \
  --data-urlencode "to=2025-12-31" \
  --data-urlencode "min_value_usd=100000000" \
  --data-urlencode "sort=-total_potential_value" \
  --data-urlencode "limit=2"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/deals",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"deal_type": "licensing", "therapeutic_area": "oncology", "from": "2025-01-01",
            "to": "2025-12-31", "min_value_usd": 100_000_000, "sort": "-total_potential_value",
            "limit": 2},
)
resp.raise_for_status()
for d in resp.json()["data"]:
    print(d["announced_at"][:10], d["deal_name"], "|", d["total_potential_value"]["amount"])
```
