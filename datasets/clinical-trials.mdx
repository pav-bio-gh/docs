A trial is one ClinicalTrials.gov study, with its sponsors and the Pav
programs and companies linked to it.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/trials` | Trials, filtered. |
| `GET /v1/trials/{nct_id}` | One trial. |

## Key fields

| Field | Description |
| --- | --- |
| `nct_id`, `nct_url`, `title` | Registry id, link and title. |
| `phase`, `status`, `study_type` | As registered (`PHASE3`, `RECRUITING`, `INTERVENTIONAL`). |
| `conditions[]`, `enrollment_count` | Conditions and enrollment. |
| `lead_sponsor`, `collaborators[]` | Sponsors, with `company_id` when linked. |
| `company_ids[]`, `programs[]` | Linked Pav companies and programs. |
| `start_date`, `primary_completion_date`, `last_update_post_date` | Registry dates. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `company` | Ticker, company slug or exact name; matches sponsors, collaborators and linked programs | `pfizer` |
| `indication` | Condition name, synonym, MeSH or MONDO id | `obesity` |
| `phase` | `1`–`4` | `2` |
| `status` | Recruitment statuses | `recruiting` |
| `study_type` | Study types | `interventional` |
| `nct_id`, `company_id` | Ids, for values from an earlier response | `NCT07668414` |
| `from`, `to` | `start_date` range | `2026-01-01` |
| `sort` | `start_date`, `last_update_post_date`, `enrollment_count`, `nct_id` (default) | `-start_date` |

## Example

Recruiting Phase 2 obesity trials, newest first:

<CodeGroup>

```bash cURL icon="braces"
curl -G https://api.pav.bio/v1/trials \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d indication=obesity \
  -d phase=2 \
  -d status=recruiting \
  -d sort=-start_date \
  -d limit=2
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

trials = client.trials.list(
    indication=["obesity"],
    phase=["2"],
    status=["recruiting"],
    sort="-start_date",
    limit=2,
)
for trial in trials.items:
    print(trial.nct_id, trial.start_date, trial.title)
```

```bash CLI icon="terminal"
pav trials list \
  --indication obesity \
  --phase 2 \
  --status recruiting \
  --sort=-start_date \
  --limit 2
```
