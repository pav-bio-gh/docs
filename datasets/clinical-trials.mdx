## Overview

A trial is one ClinicalTrials.gov study. It carries its sponsors and the Pav
programs and companies linked to it. See [Fetching Data](/fetching-data) for filters, dates, sorting and paging.

The example lists recruiting Phase 2 obesity trials, newest first.

<RequestExample>

```bash cURL icon="braces"
curl "https://api.pav.bio/v1/trials?indication=obesity&phase=2&status=recruiting&sort=-start_date&limit=2" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

trials = client.trials.list(
    indication=["obesity"],
    phase=["2"],
    status=["recruiting"],
    sort="-start_date",
    limit=2,
)
for trial in trials.items:
    print(trial.nct_id, trial.start_date, trial.title)
```

```bash CLI icon="terminal"
pav trials list \
  --indication obesity \
  --phase 2 \
  --status recruiting \
  --sort=-start_date \
  --limit 2
```

</RequestExample>
