A trial is one ClinicalTrials.gov study, with its sponsors and the Pav
programs and companies linked to it.

| Endpoint | Returns |
| --- | --- |
| `GET /v1/trials` | Trials, filtered or searched with `q`. |
| `GET /v1/trials/{nct_id}` | One trial. |
| `GET /v1/companies/{company_id}/trials` | One company's trials. |

## Key fields

| Field | Description |
| --- | --- |
| `nct_id`, `nct_url`, `title` | Registry id, link and title. |
| `phase`, `status`, `study_type` | As registered (`PHASE3`, `RECRUITING`, `INTERVENTIONAL`). |
| `conditions[]`, `enrollment_count` | Conditions and enrollment. |
| `lead_sponsor`, `collaborators[]` | Sponsors, with `company_id` when linked. |
| `company_ids[]`, `programs[]` | Linked Pav companies and programs. |
| `start_date`, `primary_completion_date`, `last_update_post_date` | Registry dates. |

## Parameters

| Name | Values | Example |
| --- | --- | --- |
| `q` | Free text, ranked by relevance | `semaglutide sleep apnea` |
| `company_id` | Ids; matches sponsors and collaborators | `76` |
| `nct_id` | NCT ids | `NCT07668414` |
| `phase` | `1`–`4` | `3` |
| `status` | Recruitment statuses | `RECRUITING` |
| `study_type` | Study types | `INTERVENTIONAL` |
| `indication` | Condition name, synonym, MeSH or MONDO id | `obesity` |
| `from`, `to` | `start_date` range | `2026-01-01` |
| `sort` | `start_date`, `last_update_post_date`, `enrollment_count`, `nct_id` (default) | `-start_date` |

Shared rules: [Conventions](/conventions).

## Example

Recruiting Phase 3 obesity trials, newest first:

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/trials \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "indication=obesity" \
  --data-urlencode "phase=3" \
  --data-urlencode "status=RECRUITING" \
  --data-urlencode "sort=-start_date" \
  --data-urlencode "limit=2"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/trials",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"indication": "obesity", "phase": "3", "status": "RECRUITING",
            "sort": "-start_date", "limit": 2},
)
resp.raise_for_status()
for t in resp.json()["data"]:
    print(t["nct_id"], t["start_date"], t["sponsor"], "|", t["title"][:60])
```
