## Overview

Each trial is a ClinicalTrials.gov study, keyed by its NCT id, with the
registry's title, phase, status, dates, conditions, enrollment and primary
outcomes. Pav adds the links: the Pav programs matched to the trial, and the
Pav companies that sponsor it or own those programs.

Questions this dataset answers:

- Which Phase 3 obesity trials are recruiting now, and who sponsors them?
- Which trials back a given program, and what are their primary endpoints?
- What are a sponsor's newest trials?

## Coverage

| Source | Links | Total counts |
| --- | --- | --- |
| ClinicalTrials.gov registry | Pav programs and sponsor companies, where matched | Not returned; `pagination.total` is always `null` |

## Key fields

| Field | Description |
| --- | --- |
| `nct_id`, `nct_url` | Registry id and study URL. |
| `title` | Study title. |
| `phase` | Registry phase, e.g. `PHASE3`. Multi-phase studies list each phase separated by a pipe character. |
| `status` | Registry status, e.g. `RECRUITING`, `COMPLETED`. |
| `sponsor` | Lead sponsor name as registered. |
| `study_type`, `conditions[]`, `enrollment_count` | Registry metadata. |
| `start_date`, `primary_completion_date`, `completion_date`, `last_update_post_date`, `results_first_post_date` | Registry dates. |
| `primary_outcomes[]` | Primary outcome measures with time frames. |
| `lead_sponsor`, `collaborators[]`, `sponsors[]` | Sponsors with their role and, when linked, Pav `company_id`. |
| `company_ids[]` | Pav companies linked to the trial as sponsor or through their programs. |
| `programs[]` | Pav programs linked to the trial. |

## Endpoints

| Endpoint | Use |
| --- | --- |
| `GET /v1/trials` | Search (`q`) or browse trials. |
| `GET /v1/trials/{nct_id}` | One trial. |
| `GET /v1/companies/{company_id}/trials` | Trials linked to one company. See [Companies](/datasets/companies). |

## Filters

| Parameter | Matches | Example |
| --- | --- | --- |
| `q` | Relevance-ranked search that matches meaning as well as exact words. | `KRAS G12C non-small cell lung cancer` |
| `phase` | Trial phase; any listed phase matches. Case and format are normalized. | `Phase 3` or `PHASE3` |
| `status` | Recruitment status. Case and format are normalized. | `Recruiting` |
| `sponsor` | Lead sponsor, exact name as registered (case-sensitive). | `Eli Lilly and Company` |
| `study_type` | Study type. | `Interventional` |
| `nct_id` | Specific trials. Repeatable. | `NCT04184622` |
| `sort`, `direction` | Browse order (not with `q`): `start_date`, `last_update`, `enrollment`, `nct_id`. | `sort=start_date&direction=desc` |
| `limit`, `offset` | Page size (1–1000, default 100). `offset + limit` must be at most 1000. | `limit=50` |

<Warning>
`/v1/trials` returns `422` for `condition`, `start_date_from`,
`start_date_to`, `include_total`, `sort` together with `q`, and
`offset + limit` above 1000. Use `q` for conditions ("obesity"), and narrow
with `phase`, `status` and `sponsor`.
</Warning>

## Search recruiting trials

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/trials \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=obesity" \
  --data-urlencode "phase=Phase 3" \
  --data-urlencode "status=Recruiting" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/trials",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "obesity", "phase": "Phase 3", "status": "Recruiting", "limit": 3},
)
resp.raise_for_status()
for t in resp.json()["data"]:
    print(t["nct_id"], "|", t["sponsor"], "|", t.get("enrollment_count"), "|", t["title"][:60])
```

```javascript JavaScript
const params = new URLSearchParams({ q: "obesity", phase: "Phase 3", status: "Recruiting", limit: "3" });
const resp = await fetch(`https://api.pav.bio/v1/trials?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const { data } = await resp.json();
for (const t of data) console.log(t.nct_id, "|", t.sponsor, "|", t.enrollment_count, "|", t.title.slice(0, 60));
```

## A sponsor's newest trials

Browse without `q` to sort. `sponsor` must match the registered name exactly.

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/trials \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "sponsor=Eli Lilly and Company" \
  --data-urlencode "sort=start_date" \
  --data-urlencode "direction=desc" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/trials",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"sponsor": "Eli Lilly and Company", "sort": "start_date", "direction": "desc", "limit": 3},
)
resp.raise_for_status()
for t in resp.json()["data"]:
    print(t["start_date"], t["nct_id"], t["phase"], t["title"][:60])
```

```javascript JavaScript
const params = new URLSearchParams({
  sponsor: "Eli Lilly and Company",
  sort: "start_date",
  direction: "desc",
  limit: "3",
});
const resp = await fetch(`https://api.pav.bio/v1/trials?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const { data } = await resp.json();
for (const t of data) console.log(t.start_date, t.nct_id, t.phase, t.title.slice(0, 60));
```

</CodeGroup>
