## Overview

Each trial is a ClinicalTrials.gov study, keyed by its NCT id, with the
registry's title, phase, status, dates, conditions, enrollment and primary
outcomes. Pav adds the links: the Pav programs of the same drug in the same
disease, and the Pav companies that sponsor the trial or own those programs.

Questions this dataset answers:

- Which Phase 3 obesity trials are recruiting now, and who sponsors them?
- Which ulcerative colitis trials started this year?
- Which trials back a given program, and what are their primary endpoints?
- Which trials changed status or posted results this week? See
  [Changes](/datasets/changes#clinical-trial-changes).

## Coverage

| Source | Links | Total counts |
| --- | --- | --- |
| ClinicalTrials.gov registry | Pav programs and sponsor companies, where matched | `include_total=true` on listings without `q`; `null` on relevance search |

## Key fields

| Field | Description |
| --- | --- |
| `nct_id`, `nct_url` | Registry id and study URL. |
| `title` | Study title. |
| `phase` | Registry phase, e.g. `PHASE3`. Multi-phase studies list each phase separated by `\|`. |
| `status` | Registry status, e.g. `RECRUITING`, `COMPLETED`. |
| `sponsor` | Lead sponsor name as registered. |
| `study_type`, `conditions[]`, `enrollment_count` | Registry metadata. |
| `start_date`, `primary_completion_date`, `completion_date`, `last_update_post_date`, `results_first_post_date` | Registry dates. |
| `why_stopped` | The registry's reason a trial stopped early, when it did. |
| `primary_outcomes[]` | Primary outcome measures with time frames. |
| `lead_sponsor`, `collaborators[]`, `sponsors[]` | Sponsors with their role and, when linked, Pav `company_id`. |
| `company_ids[]` | Pav companies linked to the trial as sponsor or through their programs. |
| `programs[]` | Pav programs linked to the trial. |

## Endpoints

| Endpoint | Use |
| --- | --- |
| `GET /v1/trials` | Search (`q`) or browse trials. |
| `GET /v1/trials/{nct_id}` | One trial. |
| `GET /v1/companies/{company_id}/trials` | Trials linked to one company. See [Companies](/datasets/companies). |
| `GET /v1/changes?entity=trial` | Changes to trials. See [Changes](/datasets/changes#clinical-trial-changes). |

## Filters

Filters combine with AND; repeating one filter matches any of its values.

| Parameter | Matches | Example |
| --- | --- | --- |
| `q` | Relevance-ranked search that matches meaning as well as exact words. A phase written in `q` ("phase 3") acts as `phase` when you pass no `phase`. | `KRAS G12C non-small cell lung cancer` |
| `condition` | A disease name or synonym, a MeSH id or a MONDO id. Includes trials filed under narrower conditions: `inflammatory bowel diseases` covers ulcerative colitis and Crohn disease. | `ulcerative colitis`, `D003093`, `MONDO:0005101` |
| `phase` | Trial phase; any listed phase matches. Case and format are normalized. | `Phase 3` or `PHASE3` |
| `status` | Recruitment status. Case and format are normalized. | `Recruiting` |
| `sponsor` | Lead sponsor, exact name as registered, case-insensitive. | `Eli Lilly and Company` |
| `company_id` | Trials linked to these Pav companies as sponsor or collaborator. | `218` |
| `study_type` | Study type. | `Interventional` |
| `start_date_from`, `start_date_to` | Start date range (`YYYY-MM-DD`, inclusive). Trials with no start date are left out. | `2025-01-01` |
| `nct_id` | Specific trials. | `NCT04184622` |
| `sort`, `direction` | Browse order (not with `q`): `start_date`, `last_update`, `enrollment`, `nct_id`. | `sort=start_date&direction=desc` |
| `include_total` | Exact match count, on listings without `q`. | `true` |
| `limit`, `offset` | Page size (1–1000, default 100). `offset + limit` must be at most 1000. | `limit=50` |

`sort` together with `q` returns `422`, because relevance search ranks by match.
A `q` with no letters or digits returns no rows.

## Search recruiting trials

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/trials \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=obesity" \
  --data-urlencode "phase=Phase 3" \
  --data-urlencode "status=Recruiting" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/trials",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={"q": "obesity", "phase": "Phase 3", "status": "Recruiting", "limit": 3},
)
resp.raise_for_status()
for t in resp.json()["data"]:
    print(t["nct_id"], "|", t["sponsor"], "|", t.get("enrollment_count"), "|", t["title"][:60])
```

```javascript JavaScript
const params = new URLSearchParams({ q: "obesity", phase: "Phase 3", status: "Recruiting", limit: "3" });
const resp = await fetch(`https://api.pav.bio/v1/trials?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const { data } = await resp.json();
for (const t of data) console.log(t.nct_id, "|", t.sponsor, "|", t.enrollment_count, "|", t.title.slice(0, 60));
```

## Trials for a condition, by start date

`condition` matches the registry's own disease classification, so it finds
every trial filed under the disease or a narrower one.

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/trials \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "condition=ulcerative colitis" \
  --data-urlencode "phase=Phase 3" \
  --data-urlencode "start_date_from=2025-01-01" \
  --data-urlencode "sort=start_date" \
  --data-urlencode "direction=desc" \
  --data-urlencode "include_total=true" \
  --data-urlencode "limit=3"
```

```python Python
import os
import requests

resp = requests.get(
    "https://api.pav.bio/v1/trials",
    headers={"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"},
    params={
        "condition": "ulcerative colitis",
        "phase": "Phase 3",
        "start_date_from": "2025-01-01",
        "sort": "start_date",
        "direction": "desc",
        "include_total": "true",
        "limit": 3,
    },
)
resp.raise_for_status()
body = resp.json()
print("total:", body["pagination"]["total"])
for t in body["data"]:
    print(t["start_date"], t["nct_id"], t["phase"], t["sponsor"])
```

```javascript JavaScript
const params = new URLSearchParams({
  condition: "ulcerative colitis",
  phase: "Phase 3",
  start_date_from: "2025-01-01",
  sort: "start_date",
  direction: "desc",
  include_total: "true",
  limit: "3",
});
const resp = await fetch(`https://api.pav.bio/v1/trials?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAV_API_KEY}` },
});
const body = await resp.json();
console.log("total:", body.pagination.total);
for (const t of body.data) console.log(t.start_date, t.nct_id, t.phase, t.sponsor);
```
