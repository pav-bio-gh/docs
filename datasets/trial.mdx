## Overview

One trial, by its ClinicalTrials.gov `nct_id`. An unknown id returns a
`404`.

<RequestExample>

```bash cURL icon="braces"
curl https://api.pav.bio/v1/trials/NCT06651281 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

trial = client.trials.get("NCT06651281")
print(trial.title, trial.status)
```

```bash CLI icon="terminal"
pav trials get --nct-id NCT06651281
```

</RequestExample>
