---

## Overview

Returns the family for a Pav `family_id` or for a member's patent, publication or
application number. `statutory_term_end` is the earliest nonprovisional
filing plus 20 years, without extensions.

<RequestExample>

```bash cURL icon="braces"
curl https://api.pav.bio/v1/patents/63129878 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

```python Python SDK icon="python"
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

family = client.patents.get(63129878)
print(family.representative_title, family.statutory_term_end)
```

```bash CLI icon="terminal"
pav patents get --family-id 63129878
```

</RequestExample>
