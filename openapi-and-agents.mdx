The OpenAPI 3.1 spec is public and needs no key:
[`https://api.pav.bio/v1/openapi.json`](https://api.pav.bio/v1/openapi.json).
Use it to generate a typed client, import the API into Postman or Bruno, or
give an agent every endpoint. The API Reference tab is built from it.

For assistants that support MCP, use the [MCP server](/mcp-server) instead.

## Tips for agents

- Start with a list call and a small `limit`, such as 5 to 25. Add
  `view=slim` on programs and patents. Fetch full records by id.
- Read `total` to count matches instead of paging through them.
- Cite `source_url`, `nct_url`, and FDA or patent numbers.
- A null field means the source does not disclose the value.
