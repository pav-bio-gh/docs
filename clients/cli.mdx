`pav` is a single binary. Its commands mirror the API: `pav <resource> list`
and `pav <resource> get`, with each query parameter as a flag.

## Install

```bash
curl -LsSf https://pav.bio/install.sh | sh
```

Installs `pav` to `~/.local/bin`. On Windows:
`powershell -c "irm https://pav.bio/install.ps1 | iex"`.

## Authenticate

```bash
pav auth login            # stores the key in your OS keychain
export PAV_API_KEY=...    # or use an environment variable
```

## List and get

```bash
pav programs list --company MRNA --phase phase_3
pav recalls list --limit 5 --sort=-document_date
pav drug-applications get --application-key N:209637
```

Output is a table in a terminal and JSON when piped. `--format json|jsonl|csv|yaml`
picks one; `--query` takes a JMESPath expression:

```bash
pav programs list --company MRNA --format json --query "data[].{drug: drug, phase: phase}"
```

## More rows

A list returns up to 200 rows per call (`--limit 200`). If there are more, the
response includes `next_cursor`; pass it back with `--cursor` for the next page:

```bash
pav programs list --modality adc --limit 200
pav programs list --modality adc --limit 200 --cursor <next_cursor>
```

To pull every row in one go, use the [Python SDK](/clients/python-sdk), which
follows the pages for you.

## For agents

`--help` and `--schema` describe every command and parameter, so an agent in
a shell can discover the API as it goes. `pav generate-skills` writes a
`SKILL.md` per command for Claude Code and similar tools.
