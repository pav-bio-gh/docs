## 1. Create an API key

Sign in at [app.pav.bio](https://app.pav.bio), open **Settings → Developer**,
and create a key. The secret is shown once.

```bash
export PAV_API_KEY="<your_api_key>"
```

## 2. List something specific — no ids needed

Preclinical antibody-drug conjugates at private companies:

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  -d phase=preclinical \
  -d modality=adc \
  -d company_type=private
```

```python Python SDK
from pav_bio import Pav

client = Pav()  # reads PAV_API_KEY

programs = client.programs.list(
    phase=["preclinical"],
    modality=["adc"],
    company_type="private",
)
for program in programs.items[:3]:
    print(program.company, program.drug, program.indication)
print("total:", programs.response.total)
```

```bash CLI
pav programs list \
  --phase preclinical \
  --modality adc \
  --company-type private
```

</CodeGroup>

## 3. Fetch one by id

```bash
curl https://api.pav.bio/v1/programs/6544 \
  -H "Authorization: Bearer $PAV_API_KEY"
```

## 4. More list examples

Phase 3 ADCs targeting HER2:

```bash
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "phase=phase_3" \
  --data-urlencode "modality=adc" \
  --data-urlencode "target=HER2"
```

Pfizer's active programs, by ticker:

```bash
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "company=PFE"
```

Oncology licensing deals announced in 2025 over $100M:

```bash
curl -G https://api.pav.bio/v1/deals \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "deal_type=licensing" \
  --data-urlencode "therapeutic_area=oncology" \
  --data-urlencode "from=2025-01-01" \
  --data-urlencode "to=2025-12-31" \
  --data-urlencode "min_value_usd=100000000"
```

Recruiting Phase 2 trials in obesity:

```bash
curl -G https://api.pav.bio/v1/trials \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "indication=obesity" \
  --data-urlencode "phase=2" \
  --data-urlencode "status=recruiting"
```

Every list returns `{ "data": [...], "next_cursor": "...", "total": N }`.
Pass `next_cursor` back as `cursor` for the next page. `company=` accepts a
ticker, a company slug or an exact registered name, and rolls up
subsidiaries; a name that matches more than one company is a `400` naming
the candidates.
