This page takes you from a new API key to your first results. You will list
preclinical antibody-drug conjugates at private companies, then fetch one of
them by id.

<Steps>
  <Step title="Create an API key">
    Sign in at [app.pav.bio](https://app.pav.bio), open **Settings → Developer**,
    and create a key. The secret is shown once, so copy it now.

    ```bash
    export PAV_API_KEY="<your_api_key>"
    ```
  </Step>
  <Step title="List programs">
    Ask for programs that match a phase, a modality and a company type.

    <CodeGroup>

    ```bash cURL icon="braces"
    curl "https://api.pav.bio/v1/programs?phase=preclinical&modality=adc&company_type=private" \
      -H "Authorization: Bearer $PAV_API_KEY"
    ```

    ```python Python SDK icon="python"
    from pav_bio import Pav

    client = Pav()  # reads PAV_API_KEY

    programs = client.programs.list(
        phase=["preclinical"],
        modality=["adc"],
        company_type="private",
    )
    for program in programs.items[:3]:
        print(program.company, program.drug, program.indication)
    print("total:", programs.response.total)
    ```

    ```bash CLI icon="terminal"
    pav programs list \
      --phase preclinical \
      --modality adc \
      --company-type private
    ```

    </CodeGroup>

    The response holds one page of matches in `data`, the number of matches in
    `total`, and a `next_cursor` for the next page.

    ```json Example response (trimmed)
    {
      "data": [
        {
          "program_id": 6544,
          "company_id": 714,
          "company": "Earendil Labs",
          "drug": "HXN-2001",
          "indication": "Colorectal cancer",
          "phase": "preclinical",
          "modality": "adc",
          "target": "CDH17"
        }
      ],
      "next_cursor": "eyJyIjoicHJvZ3JhbXMiLCJzIjoiY29tcGFueSIsInYiOiJFYXJlbmRpbCBMYWJzIiwiayI6IjY1NDQifQ",
      "total": 16
    }
    ```
  </Step>
  <Step title="Fetch one program">
    Use a `program_id` from the list to get the full record, with its trials
    and ontology terms.

    ```bash
    curl https://api.pav.bio/v1/programs/6544 \
      -H "Authorization: Bearer $PAV_API_KEY"
    ```
  </Step>
</Steps>

## More examples

Phase 3 ADCs targeting HER2:

```bash
curl "https://api.pav.bio/v1/programs?phase=phase_3&modality=adc&target=HER2" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

Pfizer's active programs, by ticker:

```bash
curl "https://api.pav.bio/v1/programs?company=PFE" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

Oncology licensing deals announced in 2025 over $100M:

```bash
curl "https://api.pav.bio/v1/deals?deal_type=licensing&therapeutic_area=oncology&from=2025-01-01&to=2025-12-31&min_value_usd=100000000" \
  -H "Authorization: Bearer $PAV_API_KEY"
```

Recruiting Phase 2 trials in obesity:

```bash
curl "https://api.pav.bio/v1/trials?indication=obesity&phase=2&status=recruiting" \
  -H "Authorization: Bearer $PAV_API_KEY"
```
