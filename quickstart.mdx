## 1. Create an API key

Sign in at [app.pav.bio](https://app.pav.bio), open **Settings → Developer**,
and create a key. The secret is shown once.

```bash
export PAV_API_KEY="<your_api_key>"
```

## 2. Find an id

Filters take ids. [Search](/search) turns a name into one.

```bash
curl -G https://api.pav.bio/v1/search \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=Eli Lilly" \
  --data-urlencode "types=company" \
  --data-urlencode "limit=1"
```

```json Example response
{ "data": [{ "type": "company", "id": "218", "name": "Eli Lilly", "detail": "United States", "program_count": 94 }] }
```

## 3. List by id

Eli Lilly's Phase 3 programs:

<CodeGroup>

```bash cURL
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "company_id=218" \
  --data-urlencode "phase=3" \
  --data-urlencode "view=slim" \
  --data-urlencode "limit=2"
```

```python Python
import os
import requests

API = "https://api.pav.bio/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['PAV_API_KEY']}"}

hit = requests.get(f"{API}/search", headers=HEADERS,
                   params={"q": "Eli Lilly", "types": "company", "limit": 1}).json()["data"][0]
resp = requests.get(f"{API}/programs", headers=HEADERS,
                    params={"company_id": hit["id"], "phase": "3", "view": "slim", "limit": 2})
resp.raise_for_status()
page = resp.json()
for p in page["data"]:
    print(p["program_id"], p["drug"], "|", p["indication"], "|", p["phase_norm"])
print("total:", page["total"])
```
