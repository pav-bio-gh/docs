## 1. Get an API key

Create a key from Pav developer settings:

```text
app.pav.bio -> Settings -> Developer
```

Keys are Clerk API keys; you can mint a personal key or an organization key.
Copy the secret when it is shown because it is not retrievable later.

```bash
export PAV_API_KEY="<your_api_key>"
```

## 2. Make a request

Search programs with a free-text query. The `q` parameter runs hybrid search;
the bearer header carries your key.

```bash
curl -G https://api.pav.bio/v1/programs \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=oral GLP-1 obesity" \
  --data-urlencode "limit=3"
```

## 3. Read the response

List endpoints return a `data` array plus a `pagination` block. Relevance-ranked
search responses may return `total: null`; `data` is ordered best-match first.

```json
{
  "data": [
    {
      "id": 18342,
      "company_id": 412,
      "company": "Example Biotech",
      "drug": "Example asset",
      "indication": "Obesity",
      "phase_norm": "phase_2",
      "clinical_trials": []
    }
  ],
  "pagination": { "limit": 3, "offset": 0 }
}
```

<Note>
Fields that are null on a row are omitted from the JSON rather than returned as
`null`.
</Note>

## 4. Try deals and patents

Deals over $1B, largest first:

```bash
curl -G https://api.pav.bio/v1/deals \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "min_value_usd=1000000000" \
  --data-urlencode "sort=headline_value" \
  --data-urlencode "limit=5"
```

Live patent families mentioning GLP-1, with their member applications:

```bash
curl -G https://api.pav.bio/v1/patents \
  -H "Authorization: Bearer $PAV_API_KEY" \
  --data-urlencode "q=GLP-1" \
  --data-urlencode "state=live" \
  --data-urlencode "include_members=true" \
  --data-urlencode "limit=5"
```
